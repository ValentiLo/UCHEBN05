

## **Что такое валидация?**

Валидация - это **проверка правильности**. Представьте, что вы принимаете заказы в кафе:
- Вы проверяете, что номер телефона клиента состоит из цифр
- Проверяете, что возраст не отрицательный
- Проверяете, что email содержит @

То же самое происходит в программировании!

---

## **Часть 1. Валидация на стороне разработчика**

Это когда **вы сами проверяете свой код** перед тем, как отправить его другим.

### **1. Аннотации типов (Type Hints)**

```python
# Без аннотаций - непонятно, что за данные
def add(a, b):
    return a + b

# С аннотациями - ясно, что ожидаем числа
def add(a: int, b: int) -> int:
    """Складывает два числа и возвращает число"""
    return a + b

# Пример использования
result = add(5, 3)  # OK
# result = add("5", "3")  # IDE подсветит ошибку
```

**Почему это важно?**
```python
def get_user_age(age: int) -> str:
    """Возвращает статус пользователя по возрасту"""
    if age >= 18:
        return "Взрослый"
    else:
        return "Ребенок"

# IDE подскажет, что age должно быть числом
get_user_age(25)      # ✅ Правильно
# get_user_age("25")  # ⚠️ IDE предупредит об ошибке
```

### **2. Проверка с помощью assert (утверждения)**

```python
def divide(a: int, b: int) -> float:
    """Деление с проверкой"""
    assert b != 0, "На ноль делить нельзя!"  # Проверка
    return a / b

# Пример
print(divide(10, 2))  # 5.0
# print(divide(10, 0))  # AssertionError: На ноль делить нельзя!
```

**Assert в реальной жизни:**
```python
def register_user(username: str, age: int):
    """Регистрация пользователя с проверками"""
```

### **3. Документирование кода (Docstrings)**

```python
def calculate_discount(price: float, discount_percent: float) -> float:
    """
    Рассчитывает цену со скидкой
    
    Args:
        price: Исходная цена (должна быть > 0)
        discount_percent: Процент скидки (от 0 до 100)
    
    Returns:
        Цена со скидкой
    
    Raises:
        ValueError: Если цена <= 0 или скидка вне диапазона
    """
    if price <= 0:
        raise ValueError("Цена должна быть положительной")
    if not 0 <= discount_percent <= 100:
        raise ValueError("Скидка должна быть от 0 до 100")
    
    return price * (100 - discount_percent) / 100

# Документацию можно посмотреть
help(calculate_discount)
```

## **Часть 2. Валидация на стороне сервера**

Это когда **ваша программа проверяет данные**, которые приходят от пользователя.

### **1. Простая валидация без библиотек**

```python
class UserValidator:
    """Простой класс для проверки данных пользователя"""
    
    @staticmethod
    def validate_email(email: str) -> bool:
        """Проверяет email (простая версия)"""
        if '@' not in email:
            return False
        if '.' not in email.split('@')[1]:
            return False
        return True
    
    @staticmethod
    def validate_phone(phone: str) -> bool:
        """Проверяет телефон (только цифры)"""
        # Убираем все кроме цифр
        digits = ''.join(filter(str.isdigit, phone))
        return len(digits) == 11  # Россия: 11 цифр
    
    @staticmethod
    def validate_age(age: int) -> bool:
        """Проверяет возраст"""
        return 0 <= age <= 120

# Использование
email = "user@example.com"
if UserValidator.validate_email(email):
    print(f"Email {email} правильный")
else:
    print(f"Email {email} неправильный")

phone = "+7-999-123-45-67"
if UserValidator.validate_phone(phone):
    print(f"Телефон {phone} правильный")
```

### **2. Валидация с помощью Pydantic (простая)**

```python
from pydantic import BaseModel, Field, ValidationError

# Определяем модель данных
class User(BaseModel):
    """Модель пользователя с правилами валидации"""
    name: str = Field(..., min_length=2, max_length=50)
    age: int = Field(..., ge=0, le=150)
    email: str
    password: str = Field(..., min_length=6)

# Создаем пользователя (автоматическая проверка!)
try:
    user = User(
        name="Иван",
        age=25,
        email="ivan@example.com",
        password="secret123"
    )
    print("✅ Пользователь создан:", user.name)
except ValidationError as e:
    print("❌ Ошибка валидации:", e)

# Попробуем с неправильными данными
try:
    user = User(
        name="A",  # Слишком короткое имя
        age=200,   # Слишком большой возраст
        email="not-email",  # Неправильный email
        password="123"  # Слишком короткий пароль
    )
except ValidationError as e:
    print("❌ Ошибки:")
    for error in e.errors():
        print(f"  - {error['loc'][0]}: {error['msg']}")
```

### **3. Практический пример: регистрация пользователя**

```python
from pydantic import BaseModel, Field, validator, ValidationError
import re

class RegistrationForm(BaseModel):
    """Форма регистрации с полной валидацией"""
    
    username: str = Field(..., min_length=3, max_length=20)
    email: str
    password: str = Field(..., min_length=6)
    confirm_password: str
    age: int = Field(..., ge=13, le=120)  # От 13 до 120 лет
    
    # Проверка email
    @validator('email')
    def validate_email(cls, v):
        if '@' not in v:
            raise ValueError('Email должен содержать @')
        if '.' not in v.split('@')[1]:
            raise ValueError('Email должен содержать домен')
        return v.lower()  # Приводим к нижнему регистру
    
    # Проверка пароля
    @validator('password')
    def validate_password(cls, v):
        if not re.search(r'[A-Z]', v):
            raise ValueError('Пароль должен содержать заглавную букву')
        if not re.search(r'[0-9]', v):
            raise ValueError('Пароль должен содержать цифру')
        return v
    
    # Проверка подтверждения пароля
    @validator('confirm_password')
    def validate_password_match(cls, v, values):
        if 'password' in values and v != values['password']:
            raise ValueError('Пароли не совпадают')
        return v

# Функция регистрации
def register_user(form_data: dict):
    """Регистрация пользователя с валидацией"""
    try:
        # Валидируем данные
        form = RegistrationForm(**form_data)
        
        # Если дошли сюда - данные правильные
        print(f"✅ Пользователь {form.username} успешно зарегистрирован!")
        print(f"   Email: {form.email}")
        print(f"   Возраст: {form.age}")
        
        # Здесь можно сохранить в базу данных
        return True
        
    except ValidationError as e:
        print("❌ Ошибки в форме:")
        for error in e.errors():
            field = error['loc'][0]
            message = error['msg']
            print(f"   • {field}: {message}")
        return False

# Тестируем
print("=== Правильные данные ===")
correct_data = {
    "username": "ivan_petrov",
    "email": "Ivan@Example.COM",
    "password": "MySecret123",
    "confirm_password": "MySecret123",
    "age": 25
}
register_user(correct_data)

print("\n=== Неправильные данные ===")
wrong_data = {
    "username": "iv",  # Слишком короткое
    "email": "not-email",  # Неправильный email
    "password": "weak",  # Слабый пароль
    "confirm_password": "different",  # Не совпадает
    "age": 5  # Слишком маленький
}
register_user(wrong_data)
```

### **4. Валидация в веб-приложении (простой пример)**

```python
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI()

# Модель для валидации входящих данных
class Product(BaseModel):
    name: str = Field(..., min_length=3, max_length=100)
    price: float = Field(..., gt=0, le=100000)
    quantity: int = Field(..., ge=0)

# База данных (в реальности используйте настоящую БД)
products_db = []

@app.post("/products/")
async def create_product(product: Product):
    """
    Создание товара.
    FastAPI автоматически валидирует данные!
    """
    # Если данные прошли валидацию - сохраняем
    products_db.append(product.dict())
    return {
        "message": "Товар создан",
        "product": product
    }

@app.get("/products/")
async def get_products(min_price: float = 0, max_price: float = 100000):
    """
    Получение товаров с фильтрацией по цене.
    Параметры тоже валидируются!
    """
    filtered = [
        p for p in products_db 
        if min_price <= p["price"] <= max_price
    ]
    return {"products": filtered}

# Запуск:
# uvicorn main:app --reload
```

### **1. Всегда проверяйте входные данные**
```python
# ❌ ПЛОХО
def get_user_name(user_id):

# ✅ ХОРОШО
def get_user_name(user_id: int) -> str:
    if user_id <= 0:
        raise ValueError("ID пользователя должен быть положительным")
    if user_id not in users:
        raise ValueError("Пользователь не найден")
    return users[user_id]
```

### **2. Используйте try-except для обработки ошибок**
```python
def safe_divide(a: str, b: str) -> float:
    """Безопасное деление с обработкой ошибок"""
    try:
        num1 = float(a)
        num2 = float(b)
        if num2 == 0:
            return float('inf')  # Бесконечность
        return num1 / num2
    except ValueError:
        print("Ошибка: введите числа!")
        return 0

# Использование
print(safe_divide("10", "2"))   # 5.0
print(safe_divide("10", "0"))   # inf
print(safe_divide("abc", "2"))  # Ошибка: введите числа! 0
```

### **3. Проверяйте типы данных**
```python
def process_age(age):
    """Обработка возраста с проверкой типа"""
    if not isinstance(age, (int, float)):
        raise TypeError("Возраст должен быть числом")

    if age < 0:
        raise ValueError("Возраст не может быть отрицательным")

    return age

# Проверка
```

```python
class UserLimits:
    """Константы для валидации"""
```

### **Пример хорошего кода:**
```python
from typing import Optional
from datetime import datetime

class OrderValidator:
    """Класс для валидации заказов"""
    
    @staticmethod
    def validate_order(
        product_name: str,
        quantity: int,
        price: float,
        customer_email: Optional[str] = None
    ) -> bool:
        """
        Проверяет корректность заказа
        
        Args:
            product_name: Название товара
            quantity: Количество (должно быть > 0)
            price: Цена (должна быть > 0)
            customer_email: Email покупателя (опционально)
            
        Returns:
            True если заказ корректен
        """
        # Проверка имени товара
        if not product_name or len(product_name.strip()) < 3:
            print("Название товара должно содержать минимум 3 символа")
            return False
        
        # Проверка количества
        if not isinstance(quantity, int) or quantity <= 0:
            print("Количество должно быть положительным целым числом")
            return False
        
        # Проверка цены
        if not isinstance(price, (int, float)) or price <= 0:
            print("Цена должна быть положительным числом")
            return False
        
        # Проверка email (если указан)
        if customer_email:
            if '@' not in customer_email or '.' not in customer_email:
                print("Некорректный email")
                return False
        
        return True

# Использование
order = OrderValidator.validate_order("Ноутбук", 2, 50000, "user@example.com")
print("Заказ корректен" if order else "Заказ содержит ошибки")
```
