# Создадим простое React-приложение с тремя страницами и навигацией между ними. Я покажу два подхода: простой (с состоянием) и профессиональный (с React Router).

## Подход 1: Простая навигация с состоянием (для начинающих)

Этот способ не требует установки дополнительных библиотек и отлично подходит для понимания базовых концепций React.

### 1. Создайте новый проект Vite (если еще не создали)
```bash
npm create vite@latest my-pages-app -- --template react
cd my-pages-app
npm install
npm run dev
```

### 2. Создайте компоненты для страниц

Создайте папку `src/components` и в ней три файла для наших страниц:

### 3. Создайте компонент навигации

**`src/components/Navigation.jsx`**
```jsx
function Navigation({ currentPage, onPageChange }) {
  const pages = [
    { id: 'home', name: 'Главная' },
    { id: 'about', name: 'О нас' },
    { id: 'contact', name: 'Контакты' }
  ];

  return (
    <nav style={styles.nav}>
      {pages.map(page => (
        <button
          key={page.id}
          onClick={() => onPageChange(page.id)}
          style={{
            ...styles.button,
            ...(currentPage === page.id ? styles.activeButton : {})
          }}
        >
          {page.name}
        </button>
      ))}
    </nav>
  );
}

const styles = {
  nav: {
    display: 'flex',
    justifyContent: 'center',
    gap: '10px',
    padding: '20px',
    backgroundColor: '#f0f0f0'
  },
  button: {
    padding: '10px 20px',
    fontSize: '16px',
    border: 'none',
    borderRadius: '5px',
    cursor: 'pointer',
    backgroundColor: '#e0e0e0',
    transition: 'all 0.3s'
  },
  activeButton: {
    backgroundColor: '#61dafb',
    color: 'white',
    fontWeight: 'bold'
  }
};

export default Navigation;
```

### 4. Обновите главный компонент App

**`src/App.jsx`**
```jsx
import { useState } from 'react';
import Navigation from './components/Navigation';
import Home from './components/Home';
import About from './components/About';
import Contact from './components/Contact';

function App() {
  const [currentPage, setCurrentPage] = useState('home');

  // Функция для отображения текущей страницы
  const renderPage = () => {
    switch (currentPage) {
      case 'home':
        return <Home />;
      case 'about':
        return <About />;
      case 'contact':
        return <Contact />;
      default:
        return <Home />;
    }
  };

  return (
    <div style={styles.app}>
      <h1 style={styles.header}>Моё приложение с тремя страницами</h1>
      <Navigation 
        currentPage={currentPage} 
        onPageChange={setCurrentPage} 
      />
      <main style={styles.main}>
        {renderPage()}
      </main>
    </div>
  );
}

const styles = {
  app: {
    fontFamily: 'Arial, sans-serif'
  },
  header: {
    textAlign: 'center',
    color: '#333',
    padding: '20px',
    margin: '0',
    backgroundColor: '#61dafb',
    color: 'white'
  },
  main: {
    padding: '20px',
    maxWidth: '800px',
    margin: '0 auto'
  }
};

export default App;
```

## Подход 2: Профессиональная навигация с React Router

Этот подход более правильный для реальных проектов, так как поддерживает историю браузера, прямые ссылки на страницы и кнопки "назад/вперед".

### 1. Установите React Router

```bash
npm install react-router-dom
```

### 4. Обновите App.jsx для работы с Router

**`src/App.jsx`**
```jsx
import { BrowserRouter, Routes, Route } from 'react-router-dom';
import NavigationRouter from './components/NavigationRouter';
import Home from './components/Home';
import About from './components/About';
import Contact from './components/Contact';

function App() {
  return (
    <BrowserRouter>
      <div style={styles.app}>
        <h1 style={styles.header}>React Router приложение</h1>
        <NavigationRouter />
        <main style={styles.main}>
          <Routes>
            <Route path="/" element={<Home />} />
            <Route path="/about" element={<About />} />
            <Route path="/contact" element={<Contact />} />
          </Routes>
        </main>
      </div>
    </BrowserRouter>
  );
}

const styles = {
  app: {
    fontFamily: 'Arial, sans-serif'
  },
  header: {
    textAlign: 'center',
    color: '#333',
    padding: '20px',
    margin: '0',
    backgroundColor: '#61dafb',
    color: 'white'
  },
  main: {
    padding: '20px',
    maxWidth: '800px',
    margin: '0 auto'
  }
};

export default App;
```

### 5. (Опционально) Добавьте 404 страницу

```jsx
    color: 'white',
    textDecoration: 'none',
    borderRadius: '5px'
  }
};

export default NotFound;
```

И добавьте маршрут для 404 в `App.jsx`:
```jsx
import NotFound from './components/NotFound';

// ... внутри <Routes>
<Route path="*" element={<NotFound />} />
```

## Преимущества второго подхода (React Router)

1. **URL-адреса**: Каждая страница имеет свой URL (/, /about, /contact)
2. **История браузера**: Работают кнопки "назад" и "вперед"
3. **Прямые ссылки**: Можно отправить ссылку на конкретную страницу
4. **Вложенные маршруты**: Легко создавать сложную структуру навигации
5. **Производительность**: Загружается только нужный компонент

## Запуск проекта

```bash
npm run dev
```

Теперь у вас есть полноценное приложение с тремя страницами и навигацией между ними! Вы можете легко добавить новые страницы, просто создав новый компонент и добавив маршрут в `App.jsx`.
