# Рабочая программа профессионального модуля
**ПМ.07 «Соадминистрирование и автоматизация баз данных и серверов»**

## 1. ПАСПОРТ РАБОЧЕЙ ПРОГРАММЫ ПРОФЕССИОНАЛЬНОГО МОДУЛЯ

### 1.1 Область применения программы
Рабочая программа профессионального модуля является частью основной профессиональной образовательной программы в соответствии с ФГОС по специальности:
- **09.02.07** «Информационные системы и программирование»
- Профиль профессионального образования: технический
- Уровень подготовки: специалист среднего звена

### 1.2 Цели и задачи модуля
**Цель:** Формирование у обучающихся профессиональных компетенций в области администрирования и автоматизации баз данных и серверов.

**Задачи:**
- Освоение методов установки, настройки и сопровождения серверного ПО
- Формирование навыков администрирования баз данных
- Изучение методов автоматизации рутинных операций администрирования
- Развитие умений мониторинга и обеспечения безопасности информационных систем
- Формирование навыков документирования процессов администрирования

### 1.3 Требования к результатам освоения модуля
В результате освоения модуля обучающийся должен:

**Знать:**
- Архитектуру клиент-серверных систем
- Принципы работы сетевых протоколов и служб
- Методы установки и настройки серверного ПО
- Основы администрирования СУБД (MySQL, PostgreSQL)
- Принципы резервного копирования и восстановления данных
- Методы мониторинга производительности систем
- Основы информационной безопасности серверов
- Языки автоматизации (Bash, PowerShell, Python)
- Средства виртуализации (Docker, VirtualBox)

**Уметь:**
- Устанавливать и настраивать серверные ОС (Linux, Windows Server)
- Развертывать и администрировать веб-серверы (Apache, Nginx)
- Управлять базами данных: создание, настройка, оптимизация
- Автоматизировать задачи администрирования с помощью скриптов
- Настраивать системы мониторинга (Zabbix, Nagios)
- Реализовывать политики резервного копирования
- Обеспечивать базовую безопасность серверов
- Документировать процессы администрирования

**Владеть:**
- Навыками работы с командной строкой
- Методами удаленного администрирования
- Технологиями виртуализации
- Инструментами мониторинга и анализа логов
- Навыками написания скриптов автоматизации

### 1.4 Количество часов на освоение программы модуля
Всего: **216 часов**
- Теоретическое обучение: 108 часов
- Практическое обучение: 108 часов
- Производственная практика: 36 часов

## 2. СТРУКТУРА И СОДЕРЖАНИЕ ПРОФЕССИОНАЛЬНОГО МОДУЛЯ

### 2.1 Учебный план

**Раздел 1. Основы администрирования серверов (72 часа)**
- Тема 1.1: Введение в серверные технологии (12 часов)
- Тема 1.2: Установка и настройка серверных ОС (20 часов)
- Тема 1.3: Сетевые службы и протоколы (16 часов)
- Тема 1.4: Веб-серверы и их настройка (24 часа)

**Раздел 2. Администрирование баз данных (60 часов)**
- Тема 2.1: Основы СУБД (12 часов)
- Тема 2.2: Установка и настройка MySQL/PostgreSQL (16 часов)
- Тема 2.3: Оптимизация и производительность БД (16 часов)
- Тема 2.4: Резервное копирование и восстановление (16 часов)

**Раздел 3. Автоматизация процессов администрирования (48 часов)**
- Тема 3.1: Основы скриптовых языков (16 часов)
- Тема 3.2: Автоматизация рутинных задач (16 часов)
- Тема 3.3: Средства мониторинга (16 часов)

**Раздел 4. Безопасность и виртуализация (36 часов)**
- Тема 4.1: Основы информационной безопасности (12 часов)
- Тема 4.2: Виртуализация серверов (12 часов)
- Тема 4.3: Контейнеризация (12 часов)

### 2.2 Практические работы

**Лабораторная работа 1:** Установка и настройка серверной ОС
- Установка Ubuntu Server / Windows Server
- Настройка сетевых интерфейсов
- Настройка удаленного доступа

**Лабораторная работа 2:** Развертывание веб-сервера
- Установка и настройка Apache/Nginx
- Настройка виртуальных хостов
- SSL-сертификаты (Let's Encrypt)

**Лабораторная работа 3:** Установка и настройка СУБД
- Установка MySQL/PostgreSQL
- Создание пользователей и прав доступа
- Настройка репликации

**Лабораторная работа 4:** Автоматизация резервного копирования
- Написание скриптов backup/restore
- Настройка cron-заданий
- Тестирование восстановления

**Лабораторная работа 5:** Мониторинг систем
- Установка и настройка Zabbix
- Создание дашбордов
- Настройка алертинга

**Лабораторная работа 6:** Безопасность серверов
- Настройка firewall (iptables/ufw)
- Аудит безопасности
- Настройка SSH-ключей

**Лабораторная работа 7:** Виртуализация
- Установка и настройка VirtualBox
- Создание виртуальных машин
- Клонирование ВМ

**Лабораторная работа 8:** Контейнеризация
- Установка Docker
- Создание Docker-образов
- Docker Compose для многоконтейнерных приложений

### 2.3 Производственная практика (36 часов)
- Самостоятельное развертывание инфраструктуры
- Решение реальных задач администрирования
- Документирование процессов
- Подготовка отчета по практике

**Практические работы оцениваются по:**
- Корректность выполнения (0-5 баллов)
- Оптимальность решений (0-3 балла)
- Документирование (0-2 балла)
- Время выполнения (0-2 балла)

**Теоретические знания оцениваются по:**
- Полнота ответа (0-5 баллов)
- Глубина понимания (0-3 балла)
- Умение применять знания (0-2 балла)
