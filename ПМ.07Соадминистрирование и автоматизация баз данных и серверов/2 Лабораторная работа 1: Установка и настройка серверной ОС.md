**Установка и настройка серверной ОС**

**Цель работы:** Освоить процесс установки серверных операционных систем, настройки сетевых интерфейсов и организации удаленного доступа.

**Задачи:**
1. Установить Ubuntu Server 22.04 LTS
2. Установить Windows Server 2022 (опционально)
3. Настроить статическую IP-адресацию
4. Настроить удаленный доступ по SSH (Linux) и RDP (Windows)
5. Провести базовую настройку системы

**Оборудование и ПО:**
- Компьютер с поддержкой виртуализации
- VirtualBox 7.0+
- Образы ОС:
  - Ubuntu Server 22.04 LTS
  - Windows Server 2022 Evaluation
- Утилиты:
  - PuTTY (для SSH)
  - mRemoteNG или Remote Desktop Connection

## Часть 1: Установка Ubuntu Server 22.04 LTS

### Шаг 1: Подготовка виртуальной машины
1. Запустите VirtualBox
2. Создайте новую виртуальную машину:
   ```bash
   Имя: Ubuntu-Server
   Тип: Linux
   Версия: Ubuntu (64-bit)
   Память: 2048-4096 MB
   Жесткий диск: 20-25 GB (VDI, динамический)
   ```

### Шаг 2: Настройка VM перед установкой
1. В настройках VM:
   - **Система → Процессор**: 2 ядра
   - **Дисплей → Видеопамять**: 16-32 MB
   - **Сеть**: Адаптер 1 → NAT
   - **Носители**: Выберите образ Ubuntu Server ISO

### Шаг 3: Установка ОС
1. Запустите VM
2. Выберите язык: **English**
3. Выберите раскладку клавиатуры: **English (US)**
4. В меню установки выберите: **Ubuntu Server**

#### Конфигурация установки:
```
1. Network connections:
   - enp0s3: DHCP (автоматически)

2. Configure proxy: (оставьте пустым)

3. Configure Ubuntu archive mirror: (по умолчанию)

4. Guided storage configuration:
   - Use entire disk
   - Storage configuration: Done

5. Profile setup:
   - Your name: Admin
   - Your server's name: ubuntu-server
   - Pick a username: admin
   - Choose a password: P@ssw0rd123 (запомните!)

6. SSH Setup:
   - [X] Install OpenSSH server
   - [ ] Import SSH identity: No

7. Featured Server Snaps: (можно пропустить)
```

8. Нажмите **Continue** для начала установки

### Шаг 4: Настройка после установки
1. После перезагрузки войдите с логином `admin` и паролем
2. Обновите систему:
   ```bash
   sudo apt update
   sudo apt upgrade -y
   ```

## Часть 2: Настройка сетевых интерфейсов

### Шаг 1: Просмотр текущей конфигурации
```bash
# Посмотреть IP-адреса
ip a

# Посмотреть таблицу маршрутизации
ip route

# Проверить подключение к интернету
ping 8.8.8.8 -c 3
```

### Шаг 2: Настройка статического IP-адреса
1. Определите сетевой интерфейс (обычно `ens33` или `enp0s3`):
   ```bash
   ip link show
   ```

2. Отредактируйте конфигурационный файл Netplan:
   ```bash
   sudo nano /etc/netplan/00-installer-config.yaml
   ```

3. Добавьте конфигурацию:
   ```yaml
   network:
     version: 2
     ethernets:
       enp0s3:
         dhcp4: no
         addresses:
           - 192.168.1.100/24
         gateway4: 192.168.1.1
         nameservers:
           addresses: [8.8.8.8, 1.1.1.1]
   ```

4. Примените изменения:
   ```bash
   sudo netplan apply
   ```

5. Проверьте настройки:
   ```bash
   ip a show enp0s3
   ```

### Шаг 3: Настройка дополнительного сетевого интерфейса (опционально)
1. Добавьте второй сетевой адаптер в VirtualBox:
   - **Сеть → Адаптер 2**: Внутренняя сеть
   
2. Настройте второй интерфейс:
   ```bash
   sudo nano /etc/netplan/00-installer-config.yaml
   ```

   ```yaml
   network:
     version: 2
     ethernets:
       enp0s3:
         dhcp4: no
         addresses:
           - 192.168.1.100/24
         gateway4: 192.168.1.1
         nameservers:
           addresses: [8.8.8.8, 1.1.1.1]
       enp0s8:
         dhcp4: no
         addresses:
           - 10.0.0.1/24
   ```

3. Примените изменения:
   ```bash
   sudo netplan apply
   ```

## Часть 3: Настройка удаленного доступа (SSH)

### Шаг 1: Базовая настройка SSH
1. Проверьте статус SSH:
   ```bash
   sudo systemctl status ssh
   ```

2. Если SSH не установлен:
   ```bash
   sudo apt install openssh-server -y
   sudo systemctl enable ssh
   sudo systemctl start ssh
   ```

### Шаг 2: Настройка безопасности SSH
1. Резервное копирование конфигурации:
   ```bash
   sudo cp /etc/ssh/sshd_config /etc/ssh/sshd_config.backup
   ```

2. Отредактируйте конфигурацию:
   ```bash
   sudo nano /etc/ssh/sshd_config
   ```

3. Измените следующие параметры:
   ```bash
   # Изменить порт (по умолчанию 22)
   Port 2222
   
   # Отключить вход под root
   PermitRootLogin no
   
   # Разрешить только определенных пользователей
   AllowUsers admin
   
   # Включить аутентификацию по ключу
   PubkeyAuthentication yes
   
   # Отключить парольную аутентификацию (после настройки ключей)
   # PasswordAuthentication no
   
   # Максимальное количество попыток входа
   MaxAuthTries 3
   
   # Время бездействия
   ClientAliveInterval 300
   ClientAliveCountMax 2
   ```

4. Перезапустите SSH:
   ```bash
   sudo systemctl restart ssh
   ```

### Шаг 3: Настройка аутентификации по ключам
1. **На клиентской машине** (Windows с PuTTY):
   - Запустите PuTTYgen
   - Генерация ключей: RSA, 2048 бит
   - Сохраните приватный ключ (id_rsa.ppk)
   - Скопируйте публичный ключ из поля "Public key"

2. **На сервере**:
   ```bash
   # Создайте папку для ключей
   mkdir -p ~/.ssh
   chmod 700 ~/.ssh
   
   # Добавьте публичный ключ
   nano ~/.ssh/authorized_keys
   # Вставьте ключ из PuTTYgen
   
   chmod 600 ~/.ssh/authorized_keys
   ```

### Шаг 4: Подключение по SSH
1. Через PuTTY:
   ```
   Host: 192.168.1.100
   Port: 2222
   Connection type: SSH
   Username: admin
   ```
   В Auth укажите путь к приватному ключу

2. Через командную строку (Linux/macOS):
   ```bash
   ssh -p 2222 admin@192.168.1.100
   ```

## Часть 4: Установка Windows Server 2022 (опционально)

### Шаг 1: Подготовка VM
1. Создайте новую VM:
   ```
   Имя: Windows-Server-2022
   Тип: Microsoft Windows
   Версия: Windows 2022 (64-bit)
   Память: 4096 MB
   Жесткий диск: 50 GB
   ```

### Шаг 2: Установка ОС
1. Запустите VM с образом Windows Server 2022
2. Выберите язык и раскладку
3. Нажмите "Установить"
4. Выберите: **Windows Server 2022 Standard (Desktop Experience)**
5. Примите лицензионное соглашение
6. Выберите: **Custom: Install Windows only**
7. Выберите диск и нажмите "Next"

### Шаг 3: Настройка после установки
1. Установите пароль администратора (P@ssw0rd123)
2. Нажмите Ctrl+Alt+Del для входа
3. Войдите с учетной записью Administrator

### Шаг 4: Настройка сети в Windows Server
1. Откройте **Server Manager**
2. Перейдите: **Local Server → Ethernet**
3. Нажмите на ссылку IPv4
4. Настройте статический IP:
   ```
   IP address: 192.168.1.200
   Subnet mask: 255.255.255.0
   Default gateway: 192.168.1.1
   DNS: 8.8.8.8
   ```

### Шаг 5: Настройка удаленного доступа (RDP)
1. В Server Manager: **Local Server → Remote Desktop**
2. Нажмите "Select users" и добавьте пользователей
3. Включите: **Allow remote connections to this computer**
4. Примените изменения
5. Для подключения используйте Remote Desktop Connection:
   ```
   Computer: 192.168.1.200
   Username: Administrator
   Password: P@ssw0rd123
   ```

## Часть 5: Практические задания

### Задание 1: Создание пользователей
**На Ubuntu Server:**
```bash
# Создать пользователя
sudo adduser user1

# Добавить пользователя в группу sudo
sudo usermod -aG sudo user1

# Проверить создание
cat /etc/passwd | grep user1
```

**На Windows Server:**
1. Server Manager → Tools → Computer Management
2. Local Users and Groups → Users
3. New User: user1, Password: P@ssw0rd123
4. Добавить в группу Administrators

### Задание 2: Настройка файрвола
**Ubuntu (UFW):**
```bash
# Включить UFW
sudo ufw enable

# Разрешить SSH
sudo ufw allow 2222/tcp

# Разрешить HTTP/HTTPS
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# Посмотреть правила
sudo ufw status verbose
```

**Windows (Firewall):**
1. Windows Defender Firewall with Advanced Security
2. Inbound Rules → New Rule
3. Port → TCP → 3389 (RDP) → Allow the connection
4. Название: RDP Access

### Задание 3: Настройка статических маршрутов
**Ubuntu:**
```bash
# Добавить маршрут
sudo ip route add 10.0.1.0/24 via 192.168.1.1

# Сохранить маршрут (в /etc/rc.local)
sudo nano /etc/rc.local
# Добавить: ip route add 10.0.1.0/24 via 192.168.1.1
```

**Windows:**
```powershell
# Добавить маршрут
route add 10.0.1.0 mask 255.255.255.0 192.168.1.1

# Сделать постоянным
route -p add 10.0.1.0 mask 255.255.255.0 192.168.1.1
```
