Напишите функцию greet(), которая принимает произвольное количество аргументов строк имен (как минимум одно) и возвращает приветствие в соответствии с образцом.

Примечание 1. Обратите внимание, что функция должна принимать не список, а именно произвольное количество аргументов.

Примечание 2. Приведенный ниже код:

print(greet('Timur'))

print(greet('Timur', 'Roman'))

print(greet('Timur', 'Roman', 'Ruslan'))

                  
должен выводить:

Hello, Timur!

Hello, Timur and Roman!

Hello, Timur and Roman and Ruslan!

                  
Примечание 3. Функция greet() должна принимать как минимум один обязательный аргумент!

Примечание 4. Вызывать функцию greet() не нужно, требуется только реализовать.


Вот реализация функции `greet()`, которая принимает произвольное количество строковых аргументов (минимум один) и формирует приветствие в требуемом формате:

```python
def greet(first_name, *other_names):
    names = [first_name] + list(other_names)
    if len(names) == 1:
        return f"Hello, {names[0]}!"
    else:
        joined_names = " and ".join(names)
        return f"Hello, {joined_names}!"
```

Объяснение решения:

1. **Параметры функции**:
   - `first_name` — обязательный аргумент (принимает первое имя)
   - `*other_names` — параметр, который собирает все остальные переданные имена в кортеж

2. **Логика работы**:
   - Сначала объединяем первое имя и остальные имена в один список `names`
   - Если передан только один аргумент (`other_names` пуст), возвращаем приветствие для одного имени
   - Если аргументов больше одного, объединяем все имена через `" and "` и формируем строку приветствия

3. **Особенности**:
   - Функция принимает как минимум один обязательный аргумент (требование задания)
   - Может обрабатывать любое количество дополнительных аргументов
   - Соответствует шаблону вывода из примеров

Примеры работы (для проверки):
```python
print(greet('Timur'))                   # Hello, Timur!
print(greet('Timur', 'Roman'))          # Hello, Timur and Roman!
print(greet('Timur', 'Roman', 'Ruslan')) # Hello, Timur and Roman and Ruslan!
```
