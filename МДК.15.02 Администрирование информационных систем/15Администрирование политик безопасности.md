

### 1. **ЛЕКЦИЯ: Основы администрирования политик безопасности**

#### 1.1. Что такое политика безопасности?
**Политика безопасности** — это совокупность документированных правил, процедур и практических приемов, которые регулируют управление, защиту и распределение информации в организации.

**Основные цели:**
- Конфиденциальность (доступ только авторизованным пользователям)
- Целостность (защита от несанкционированных изменений)
- Доступность (гарантированный доступ к информации)

#### 1.2. Уровни политик безопасности

| Уровень | Описание | Примеры |
|---------|----------|---------|
| **Верхний уровень** | Стратегические документы | Политика информационной безопасности предприятия |
| **Средний уровень** | Тактические правила | Политика паролей, политика доступа в интернет |
| **Нижний уровень** | Операционные инструкции | Инструкции по настройке Firewall, ACL |

#### 1.3. Компоненты администрирования безопасности

```
┌─────────────────────────────────────┐
│   АДМИНИСТРИРОВАНИЕ ПОЛИТИК БЕЗОПАСНОСТИ   │
├─────────────────────────────────────┤
│ • Управление учетными записями      │
│ • Политика паролей                  │
│ • Права доступа (ACL)                │
│ • Аудит и мониторинг                │
│ • Шифрование данных                 │
│ • Резервное копирование             │
└─────────────────────────────────────┘
```

### 2. **ПРАКТИЧЕСКАЯ РАБОТА №1: Настройка локальных политик безопасности в Windows**

#### Цель работы:
Научиться настраивать базовые политики безопасности в ОС Windows через оснастку "Локальная политика безопасности".

#### Оборудование:
- ПК с Windows 10/11 (или Windows Server)
- Учетная запись с правами администратора

#### Ход работы:

**Задание 1.1: Настройка политики паролей**

1. Откройте оснастку: `Win + R` → введите `secpol.msc` → Enter
2. Перейдите: **Политики учетных записей** → **Политика паролей**
3. Настройте следующие параметры:

| Параметр | Рекомендуемое значение |
|----------|----------------------|
| Минимальная длина пароля | 8 символов |
| Требования к сложности | Включена |
| Максимальный срок действия | 42 дня |
| Минимальный срок действия | 1 день |
| Хранить историю паролей | 5 паролей |

**Задание 1.2: Настройка блокировки учетной записи**

1. Перейдите: **Политики учетных записей** → **Политика блокировки учетной записи**
2. Настройте:

| Параметр | Значение |
|----------|----------|
| Порог блокировки | 5 попыток |
| Длительность блокировки | 15 минут |
| Сброс счетчика блокировок | 15 минут |

**Задание 1.3: Настройка прав пользователей**

1. Перейдите: **Локальные политики** → **Назначение прав пользователя**
2. Настройте доступ:
   - **Запрет локального входа в систему** → добавить "Гости"
   - **Запрет входа через службу терминалов** → добавить "Все"

### 3. **ПРАКТИЧЕСКАЯ РАБОТА №2: Настройка групповых политик в домене Active Directory**

#### Цель работы:
Научиться создавать и применять групповые политики (GPO) для централизованного управления безопасностью.

#### Необходимо:
- Контроллер домена (Windows Server)
- Клиентская машина в домене

#### Ход работы:

**Задание 2.1: Создание GPO для политики паролей домена**

1. Откройте **Управление групповой политикой** (`gpmc.msc`)
2. Создайте новый объект GPO с именем `Password_Policy`
3. Настройте: `Computer Configuration → Policies → Windows Settings → Security Settings → Account Policies → Password Policy`
4. Установите параметры:
   - Enforce password history: 5
   - Maximum password age: 30 days
   - Minimum password length: 8
   - Password must meet complexity requirements: Enabled

**Задание 2.2: Ограничение доступа к панели управления**

1. В том же GPO перейдите: `User Configuration → Policies → Administrative Templates → Control Panel`
2. Включите политику **"Запретить доступ к панели управления и настройкам ПК"**

**Задание 2.3: Применение GPO к организационному подразделению (OU)**

1. Создайте OU `Студенты_ИС_312`
2. Переместите туда тестового пользователя
3. Привяжите созданный GPO к этой OU
4. Выполните `gpupdate /force` на клиенте

### 4. **ПРАКТИЧЕСКАЯ РАБОТА №3: Настройка межсетевого экрана (Firewall)**

#### Цель работы:
Настроить правила фильтрации трафика на уровне хоста.

#### Задание 3.1: Базовые правила Windows Firewall

1. Откройте **Брандмауэр Защитника Windows** (`wf.msc`)
2. Создайте правило для запрета входящих подключений:
   - Тип: **Правило для порта**
   - Протокол: TCP
   - Порт: 3389 (RDP)
   - Действие: Заблокировать
   - Применять для всех профилей

3. Создайте правило для разрешения работы приложения:
   - Тип: **Правило для программы**
   - Путь: `C:\Program Files\MyApp\app.exe`
   - Разрешить подключение

#### Задание 3.2: Настройка через командную строку (PowerShell)

```powershell
# Блокировка порта
New-NetFirewallRule -DisplayName "Block_Telnet" -Direction Inbound -LocalPort 23 -Protocol TCP -Action Block

# Разрешение порта для конкретной подсети
New-NetFirewallRule -DisplayName "Allow_Web_Dev" -Direction Inbound -LocalPort 3000 -Protocol TCP -RemoteAddress 192.168.1.0/24 -Action Allow

# Просмотр всех правил
Get-NetFirewallRule | Where-Object {$_.Enabled -eq $true}
```

### 5. **ПРАКТИЧЕСКАЯ РАБОТА №4: Аудит безопасности и мониторинг событий**

#### Цель работы:
Научиться настраивать аудит событий безопасности и анализировать журналы.

#### Задание 4.1: Настройка политик аудита

1. Откройте `secpol.msc` → **Локальные политики** → **Политика аудита**
2. Включите аудит для:

| Событие | Настройка |
|---------|-----------|
| Аудит входа в систему | Успех и отказ |
| Аудит управления учетными записями | Успех и отказ |
| Аудит доступа к объектам | Только отказ |
| Аудит изменения политики | Успех и отказ |

#### Задание 4.2: Анализ событий в Просмотре событий

1. Откройте **Просмотр событий** (`eventvwr.msc`)
2. Изучите логи:
   - **Журналы Windows** → **Безопасность**
   - Найдите события с ID:
     - 4624: Успешный вход
     - 4625: Неудачный вход
     - 4647: Инициация выхода
     - 4720: Создание пользователя

#### Задание 4.3: PowerShell для анализа событий

```powershell
# Поиск неудачных попыток входа за последние 24 часа
Get-EventLog -LogName Security -InstanceId 4625 -After (Get-Date).AddDays(-1)

# Экспорт событий в CSV
Get-EventLog -LogName Security -EntryType FailureAudit | Export-Csv -Path "C:\audit.csv"
```
