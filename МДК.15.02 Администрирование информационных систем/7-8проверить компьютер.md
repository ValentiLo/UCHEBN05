# 🖥️ **Простая инструкция: Как проверить компьютер сисадмину**

## 📋 **Быстрая проверка за 10 минут (для любого пользователя)**

### **1. Включи и посмотри на загрузку**
```
⏱️ Сколько секунд до рабочего стола?
🔊 Есть ли звуковые ошибки (писки)?
❌ Синие экраны при загрузке?
```

### **2. Проверь самое очевидное**
```
✅ Интернет работает? (открой Яндекс)
✅ Звук есть? (включи видео на YouTube)
✅ Мышь и клавиатура работают?
✅ Все ли клавиши нажимаются?
✅ Монитор: все ли цвета нормальные?
```

### **3. Посмотри "здоровье" компьютера**
**Правой кнопкой на "Этот компьютер" → Свойства:**
```
💻 Сколько оперативной памяти (ОЗУ)?
💾 Сколько места на диске C: свободно?
⚙️ Какой процессор и частота?
```

---

## 🔧 **Углублённая проверка (для сисадмина)**

### **4. Проверка через "Диспетчер задач" (Ctrl + Shift + Esc)**
```
📊 Вкладка "Производительность":
- Загрузка CPU (процессора) — в норме до 30% в простое
- Память — сколько свободно (должно быть минимум 25%)
- Диск — не должен быть загружен на 100%
- Сеть — есть ли активность?

📋 Вкладка "Автозагрузка":
- Что грузится при старте? Отключить лишнее!
```

### **5. Проверка температуры (если компьютер тормозит)**
```
1. Скачай бесплатную HWMonitor
2. Запусти и посмотри температуры:
   - CPU (процессор) — норма до 70°C
   - GPU (видеокарта) — норма до 80°C
   - Диски — норма до 50°C
3. Если больше — нужно чистить от пыли!
```

### **6. Проверка диска на ошибки**
**Командная строка (от имени администратора):**
```
chkdsk C: /f
```
Или через свойства диска:
```
ПКМ на диск C: → Свойства → Сервис → Проверить
```

### **7. Проверка оперативной памяти**
```
1. Нажми Win + R
2. Введи mdsched.exe
3. Перезагрузи и дождись проверки
4. Если найдутся ошибки — память неисправна
```

---

## 🛡️ **Проверка безопасности**

### **8. Антивирус и обновления**
```
✅ Есть ли антивирус? (обычно иконка в трее справа внизу)
✅ Когда последнее обновление?
✅ Полная проверка запускалась? (запусти сейчас)

Windows Update:
1. Пуск → Настройки → Обновление и безопасность
2. Проверить наличие обновлений
3. Установить все важные обновления
```

### **9. Проверка пользователей и прав**
```
1. Win + R → lusrmgr.msc → Пользователи
2. Кто есть в группе "Администраторы"?
3. У пользователя обычные права или админские?
4. Есть ли лишние учётные записи?

Правильно: 
- Один администратор (вы или ИТ-отдел)
- Все остальные — обычные пользователи
```

### **10. Проверка сетевых настроек**
```
1. Win + R → ncpa.cpl
2. Правой кнопкой на подключении → Состояние
3. Смотрим:
   - Скорость (должна быть 100/1000 Мбит)
   - Отправлено/получено пакетов (не должно быть ошибок)
   - IPv4 адрес (обычно 192.168.x.x)

4. Командная строка: ipconfig /all
   - Основной шлюз (роутер)
   - DNS-серверы
```

## 📊 **Проверка установленного ПО**

### **11. Что установлено на компьютере?**
```
1. Панель управления → Программы и компоненты
2. Сортируем по дате установки
3. Ищем:
   - Лишний софт (игры, тулбары)
   - Нелицензионное ПО
   - Устаревшие версии программ
   - Дубликаты (например, 2 антивируса)
```

### **12. Проверка лицензий**
```
✅ Windows активирована? (ПКМ на "Этот компьютер" → Свойства)
✅ Офис активирован? (открой Word → Файл → Учетная запись)
✅ Специализированный софт (1С, AutoCAD и т.д.)
```

## 🔍 **Диагностика проблем**

### **13. Если компьютер тормозит**
```
1. Диспетчер задач → что грузит систему?
2. Автозагрузка → отключить всё лишнее
3. Очистка диска: Win + R → cleanmgr
4. Дефрагментация (для HDD): Win + R → dfrgui
5. Проверка на вирусы
```

### **14. Если нет интернета**
```
1. Проверь кабель/Wi-Fi
2. Командная строка: 
   ping 8.8.8.8 (проверка связи)
   ping ya.ru (проверка DNS)
   ipconfig /release и ipconfig /renew (обновить IP)
3. Проверь настройки прокси: 
   Win + R → inetcpl.cpl → Подключения → Настройка сети
```

### **15. Если синий экран**
```
1. Запиши код ошибки (например, 0x0000007B)
2. Win + R → eventvwr.msc 
   Windows Журналы → Система
   Ищем ошибки за сегодня
3. Скачай BlueScreenView для анализа дампов
```

## 🛠️ **Инструменты для проверки (бесплатные)**

### **Must have (должны быть на флешке):**
```
1. HWMonitor — температуры
2. CrystalDiskInfo — здоровье дисков
3. Speccy — полная информация о железе
4. CCleaner — очистка (осторожно!)
5. AdwCleaner — удаление рекламного ПО
```

### **Как пользоваться:**
1. Скачай на флешку
2. Запусти на проверяемом компьютере
3. Посмотри отчёты
4. Удали после проверки

## 💼 **Для корпоративных компьютеров дополнительно**

### **1. Проверка политик безопасности**
```
1. Win + R → secpol.msc
2. Проверить:
   - Политики паролей
   - Блокировку учетной записи
   - Права пользователей
```

### **2. Проверка подключения к домену**
```
1. ПКМ на "Этот компьютер" → Свойства
2. Смотрим: рабочая группа или домен?
3. Если домен: 
   - Командная строка: nltest /dsgetdc:ИМЯ_ДОМЕНА
   - Проверить, доступны ли контроллеры домена
```

### **3. Проверка сетевых принтеров и ресурсов**
```
1. Win + R → control printers
2. Все ли нужные принтеры установлены?
3. Win + E → в адресной строке: \\server
4. Доступны ли сетевые папки?
```

## 🎪 **Простая аналогия**

**Проверка компьютера как осмотр машины у механика:**

1. **Внешний осмотр** (загрузка, звуки, экран)
2. **Пробный запуск** (интернет, программы)
3. **Диагностика под капотом** (температуры, ошибки диска)
4. **Проверка документов** (лицензии, пользователи)
5. **Тест-драйв** (производительность в работе)

---

## ⚠️ **Что должно насторожить**

**Немедленно решать:**
```
🔥 Температура CPU > 80°C
🔥 Место на диске C: < 10% свободно
🔥 Ошибки диска в CrystalDiskInfo
🔥 Вирусы или майнеры в процессах
🔥 Нелицензионное ПО в бизнесе
```

**Планово решать:**
```
⚠️ Компьютер старше 5 лет
⚠️ Меньше 8 ГБ ОЗУ
⚠️ HDD вместо SSD
⚠️ Нет антивируса/обновлений
⚠️ Пользователь работает из-под админа
```

## 💎 **Краткий алгоритм на каждый день**

**За 5 минут:**
1. Запустил → посмотрел время загрузки
2. Открыл Диспетчер задач → глянул загрузку CPU и памяти
3. Проверил свободное место на диске
4. Убедился, что антивирус работает
5. Спросил пользователя: "Что беспокоит?"

**И записал в табличку:**  
`Компьютер №5 | 25 сек | CPU 15% | 45ГБ свободно | Антивирус ✅ | Жалоб нет`

## 🆘 **Если нашел проблему**

1. **Можно решить сразу** (пыль, автозагрузка) → реши
2. **Нужно время** (замена железа) → запланируй
3. **Критично для бизнеса** (нет интернета) → срочно решай
4. **Нужны деньги** (новый компьютер) → докладывай начальству

**Главное:** Не молчи о проблемах! Лучше сказать "вот что я нашел, нужно вот это", чем "всё нормально", а потом случится авария.

**Удачи в проверках!** 🛠️💻
