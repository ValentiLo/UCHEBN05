## 🛠️ **ШАГ 5: План действий (приоритеты)**

### **СЕЙЧАС (сегодня):**
1. **Удалить вирус/майнер:**
   ```cmd
   taskkill /f /im miner.exe
   del C:\Users\Мария\AppData\Roaming\miner.exe
   ```
2. **Очистить диск:**
   - Win + R → `cleanmgr` → очистить системные файлы
   - Удалить временные файлы (вручную: `C:\Windows\Temp`)
   - Перенести документы бухгалтера на диск D: или сетевой ресурс

3. **Настроить автозагрузку:**
   - Оставить только антивирус и 1С
   - Всё остальное отключить

### **В ЭТУ НЕДЕЛЮ:**
4. **Настроить антивирус:**
   - Обновить базы
   - Запустить полную проверку
   - Настроить регулярные проверки

5. **Сменить права пользователя:**
   - Создать учётную запись с правами администратора для ИТ
   - Сделать Марию обычным пользователем

6. **Установить обновления Windows**
