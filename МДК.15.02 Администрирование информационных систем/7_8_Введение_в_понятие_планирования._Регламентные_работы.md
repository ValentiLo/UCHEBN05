# Администрирование информационных систем: планирование и регламентные работы

## Введение в понятие планирования

**Планирование** в администрировании информационных систем — это процесс заблаговременного определения того, какие задачи нужно выполнить, когда их делать, какие ресурсы потребуются и как организовать работу для поддержания стабильной и безопасной работы системы.

**Зачем нужно планирование:**
- Предотвращение проблем до их возникновения
- Эффективное использование времени и ресурсов
- Обеспечение непрерывной работы системы
- Соблюдение сроков выполнения работ
- Подготовка к нештатным ситуациям

**Уровни планирования:**
- **Стратегическое** (на годы вперед) — замена оборудования, переход на новые технологии
- **Тактическое** (на месяцы) — внедрение новых систем, обновление ПО
- **Оперативное** (ежедневное/еженедельное) — регулярное обслуживание, мониторинг

## Регламентные работы

**Регламентные работы** — это регулярные, повторяющиеся задачи по обслуживанию системы, которые выполняются по заранее составленному графику.

### Основные виды регламентных работ:

**1. Ежедневные задачи:**
- Проверка работоспособности системы
- Контроль свободного места на дисках
- Мониторинг журналов событий и ошибок
- Проверка успешности резервного копирования
- Контроль работы критически важных служб

**2. Еженедельные задачи:**
- Полное резервное копирование данных
- Очистка временных файлов
- Обновление антивирусных баз
- Анализ статистики использования ресурсов
- Проверка целостности системных файлов

**3. Ежемесячные задачи:**
- Установка обновлений безопасности
- Архивация старых логов
- Ревизия прав доступа пользователей
- Проверка аппаратного состояния
- Обновление документации

**4. Квартальные/годовые задачи:**
- Тестовое восстановление из резервных копий
- Аудит системы безопасности
- Пересмотр политик доступа
- Плановый ремонт и обслуживание оборудования
- Обучение и аттестация пользователей

## Основные функции операционной системы

Операционная система (ОС) — это главная программа, которая управляет всем компьютером. Её основная задача — распределять ресурсы компьютера между разными задачами и пользователями.

### Что делает операционная система:
- **Загружает и запускает программы** — помещает их в оперативную память и обеспечивает их выполнение
- **Распределяет память** — делит память между программами и самой ОС
- **Управляет хранилищами данных** — работает с дисками, флэш-памятью, организует файловую систему
- **Обеспечивает многозадачность** — позволяет работать нескольким программам одновременно (или по очереди на одном процессоре)
- **Защищает систему** — предотвращает сбои и ошибки, защищает от несанкционированного доступа
- **Управляет устройствами** — принтерами, сканерами, модемами и другим оборудованием
- **Проверяет пользователей** — выполняет аутентификацию (проверка логина/пароля) и авторизацию (определение прав доступа)
- **Собирает информацию** — диагностирует проблемы и собирает статистику работы системы

## Связь планирования с регламентными работами

**Планирование определяет КАК и КОГДА** выполнять регламентные работы:
1. **Составление календаря работ** — график выполнения всех регулярных задач
2. **Определение приоритетов** — какие задачи важнее всего
3. **Распределение ответственности** — кто какую работу выполняет
4. **Подготовка ресурсов** — что потребуется для выполнения работ
5. **Резервирование времени** — выделение временных окон для обслуживания

### Пример плана регламентных работ:

**Понедельник:**
- 08:00 — Проверка работоспособности после выходных
- 12:00 — Контроль дискового пространства
- 18:00 — Ежедневное резервное копирование

**Вторник:**
- 10:00 — Обновление антивирусных баз
- 15:00 — Анализ логов безопасности

**Среда:**
- 22:00 — Полное резервное копирование
- Ночное время — Установка обновлений (если требуется)

**Четверг:**
- 11:00 — Проверка работы периферийных устройств
- 16:00 — Контроль производительности системы

**Пятница:**
- 09:00 — Генерация недельных отчетов
- 14:00 — Планирование работ на следующую неделю

## Как администратор управляет системой

Администратор системы настраивает ОС через:
1. **Параметры ядра** — основные настройки системы, задаются при установке
2. **Специальные утилиты** — программы для управления разными аспектами системы
3. **Средства автоматизации** — скрипты и программы для регулярных задач

### Основные задачи администратора:
- **Регламентные задачи:**
  - Ежедневное резервное копирование
  - Регулярное обновление ПО
  - Периодическая очистка системы
  - Плановые проверки безопасности

- **Оперативные задачи:**
  - Создание и настройка учетных записей пользователей
  - Назначение прав доступа к файлам и папкам
  - Контроль использования ресурсов
  - Управление очередями печати
  - Отправка сообщений пользователям
  - Мониторинг работы системы

## Установка и настройка операционной системы

### Подготовка к установке
Перед установкой ОС необходимо:

**Планирование установки:**
1. Определить цели и требования к системе
2. Выбрать подходящую операционную систему
3. Составить план работ и временной график
4. Подготовить необходимое оборудование
5. Спланировать структуру будущей системы

2. **Проверить условия эксплуатации:**
   - Температура и влажность в помещении
   - Достаточно ли места для оборудования
   - Соответствует ли электропроводка требованиям:
     * Специальные линии питания для компьютеров
     * Заземленные розетки
     * Стабильное напряжение

3. **Подготовить установочные носители:**
   - Создать рабочие копии дистрибутива
   - Оригинальные диски хранить в безопасном месте

4. **Определить тип установки:**
   - Новая установка (чистая инсталляция)
   - Обновление существующей системы

### Подготовительная документация
Перед установкой заполняется рабочая таблица с информацией о сервере:

- **Общая информация:** название, модель сервера
- **Аппаратное обеспечение:** 
  * Объем оперативной памяти
  * Процессор (модель и скорость)
  * Сетевые платы (тип, настройки, драйверы)
  * Дисковые системы (емкость, тип контроллера)
  * Другие платы и устройства

### Процесс установки
1. **Запуск установки** — с помощью программы Install или Setup
2. **Копирование системных файлов** на жесткий диск
3. **Установка драйверов** для оборудования (автоматически или вручную)
4. **Настройка ядра ОС** — задание основных параметров:
   - Имя сервера
   - Данные администратора (логин и пароль)
   - Сетевые настройки (например, TCP/IP)
   - Настройки безопасности (шифрование паролей)
   - Параметры печати
   - Настройки мониторинга

5. **Установка на рабочие станции** — аналогичная настройка на компьютерах пользователей
6. **Настройка сети** — конфигурация сетевых плат и драйверов

### После установки — планирование структуры
После установки ОС администратор должен создать:

1. **Структуру каталогов:**
   - Системные папки (создаются автоматически)
   - Папки для прикладных программ
   - Общие папки для обмена файлами
   - Пользовательские папки

2. **Пользователей и группы:**
   - Создание учетных записей пользователей
   - Объединение пользователей в группы (по отделам, ролям)
   - Назначение прав доступа для групп и отдельных пользователей

3. **Систему защиты:**
   - Настройка атрибутов файлов и папок (только чтение, скрытый, системный)
   - Разграничение прав (кто что может делать)

### Настройка входа пользователей
При входе в систему выполняются два типа настроек:

1. **Системные настройки** (для всех пользователей):
   - Общие приветственные сообщения
   - Подключение сетевых дисков
   - Настройка общего окружения

2. **Пользовательские настройки** (индивидуальные):
   - Персональные настройки рабочего стола
   - Индивидуальные права доступа
   - Личные папки и файлы

## Важность планирования регламентных работ

### Преимущества регулярного планирования:
1. **Предсказуемость** — все знают, когда и какие работы будут выполняться
2. **Минимизация простоев** — работы планируются на наименее загруженное время
3. **Профилактика проблем** — регулярное обслуживание предотвращает серьезные сбои
4. **Рациональное использование ресурсов** — оборудование и персонал используются оптимально
5. **Соблюдение требований** — выполнение нормативов по безопасности и надежности

### Что включает план регламентных работ:
- **Перечень всех регулярных операций**
- **Частоту выполнения** каждой операции
- **Время выполнения** (с учетом нагрузки на систему)
- **Продолжительность** каждой операции
- **Ответственных исполнителей**
- **Процедуры отката** на случай проблем
- **Критерии успешного выполнения**

## Инструменты для планирования и выполнения работ

### Для планирования:
- Календари и планировщики задач
- Системы управления проектами
- Чек-листы и шаблоны документов

### Для автоматизации:
- **Планировщики задач:** Windows Task Scheduler, cron (Linux)
- **Системы мониторинга:** для отслеживания состояния системы
- **Скрипты и программы:** для автоматического выполнения задач

## Вывод

**Планирование и регламентные работы** — основа стабильной работы любой информационной системы. Без регулярного планового обслуживания даже самая современная система быстро выйдет из строя или станет неэффективной.

**Правильное планирование позволяет:**
- Избежать внезапных сбоев
- Своевременно выявлять и устранять проблемы
- Эффективно использовать ресурсы
- Обеспечивать безопасность данных
- Поддерживать систему в работоспособном состоянии

Администратор должен не только уметь настраивать и управлять системой, но и грамотно планировать все работы по её обслуживанию, создавая и соблюдая регламенты регулярного обслуживания. Это превращает администрирование из реакции на проблемы в проактивное управление, обеспечивающее стабильность и надежность информационной системы.
