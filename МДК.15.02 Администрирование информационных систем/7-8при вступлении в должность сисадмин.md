# 📋 **Чек-лист для нового сисадмина: Первые шаги на новой работе**

## 🎯 **День 1-2: Безопасность и выживание**

### **1. Получи доступ ко всему (пароли и учётки)**
```
✅ Аккаунт администратора домена
✅ Роутер/маршрутизатор
✅ Серверы (физические/виртуальные)
✅ Резервные копии
✅ Облачные сервисы (почта, документы)
✅ CRM и базы данных
✅ Камеры и СКУД (система контроля доступа)
✅ Принтеры и МФУ
```

**Простой вопрос начальнику:** *"Где у нас лежат пароли? Есть ли менеджер паролей (KeePass, LastPass)?"*

### **2. Найди "аварийный чемоданчик"**
```
✅ Контакты: кто отвечает за что
✅ Ключи от серверной
✅ Запасной ноутбук/телефон
✅ Диски с ОС и ПО
✅ Документация сети (схемы, IP-адреса)
✅ Контакты поставщиков (интернет, телефония)
```

### **3. Познакомься с ключевыми людьми**
```
❓ Кто главный по финансам (заказ оборудования)?
❓ Кто отвечает за безопасность?
❓ Кто "критический пользователь" (бухгалтер, директор)?
❓ Кто предыдущий админ (можно позвонить)?
❓ Есть ли ИТ-подрядчики?
```

---

## 🔍 **Первая неделя: Диагностика**

### **4. Карта сети (нарисуй в тетради)**
```
1. Какой интернет? (провайдер, скорость)
2. Роутер — где стоит, модель
3. Коммутаторы — сколько, где
4. Серверы — что на них крутится
5. Wi-Fi — покрытие, пароль
6. Принтеры — кто к какому подключен
```

**Метод:** Просто обойди все этажи с листиком.

### **5. Проверь самое страшное: резервные копии**
```
✅ ЕСТЬ ЛИ БЭКАПЫ ВООБЩЕ?
✅ Что копируется (файлы, базы, почта)?
✅ Куда (диск, лента, облако)?
✅ Кто проверяет, что они восстанавливаются?
✅ Когда последний раз восстанавливали?
```

**Простой тест:** *"Давайте сегодня попробуем восстановить один файл из вчерашней копии"*

### **6. Оцени "пожароопасность"**
```
🔥 Старые компьютеры (больше 5 лет)
🔥 Перегрев (пыль в системниках)
🔥 Виснущие программы
🔥 Вечно жалуются на что-то
🔥 Нет антивируса/обновлений
🔥 Общие пароли ("qwerty123")
```

---

## 📊 **Вторая неделя: Систематизация**

### **7. Создай "базу знаний" (даже в обычном файле)**
```
Файл 1: Пароли (зашифрованный архив)
Файл 2: Контакты
Файл 3: Инструкции (как что перезагрузить)
Файл 4: Проблемы (что постоянно ломается)
Файл 5: Пожелания пользователей
```

### **8. Проверь лицензии**
```
✅ Windows на компьютерах
✅ Офис (Word, Excel)
✅ Антивирус
✅ Специализированное ПО (1С, AutoCAD)
✅ Облачные подписки
```

**Важно:** Нелегальное ПО = штрафы компании.

### **9. Узнай "боли" пользователей**
Спроси у 3-5 человек:
```
❓ "Что больше всего раздражает в технике?"
❓ "Что чаще всего ломается?"
❓ "Чего не хватает для работы?"
❓ "Какие планы по развитию отдела?"
```

---

## 🚨 **Что делать в первую очередь, если всё плохо**

### **Приоритет 1: Чтобы не уволили сразу**
```
1. Наладить почту директора
2. Наладить интернет
3. Наладить 1С/базу данных (если есть)
4. Сделать резервную копию СЕЙЧАС
```

### **Приоритет 2: Чтобы не было пожара**
```
1. Проверить дым/запах в серверной
2. Проверить ИБП (источники бесперебойного питания)
3. Убедиться, что кондиционер в серверной работает
4. Убрать кабели с проходов
```

### **Приоритет 3: Первые победы**
Выбери 2-3 простые задачи, которые:
- Быстро решаются
- Заметны всем
- Не требуют денег

**Примеры:**
- Починить вечно зависающий принтер
- Ускорить самый медленный компьютер
- Навести порядок в проводах
- Создать инструкцию "как подключиться к Wi-Fi"

---

## 💬 **Вопросы, которые нужно задать начальству**

### **Технические:**
1. *"Есть ли схема сети?"*
2. *"Какой самый критичный сервис? (если упадёт — компания теряет деньги)"*
3. *"Когда последний раз покупали компьютеры?"*
4. *"Есть ли бюджет на ИТ в этом году?"*

### **Организационные:**
1. *"Как вы видите мои первые 30 дней?"*
2. *"Какие 3 главные проблемы нужно решить в первую очередь?"*
3. *"Кто мой непосредственный начальник и как часто отчитываться?"*
4. *"Можно ли заказывать оборудование самому или через кого-то?"*

## 🎪 **Простая аналогия**

Представь, что тебе передали **чужую машину**:

1. **Сначала:** Проверить тормоза, бензин, ключи (безопасность)
2. **Потом:** Разобраться, как включается свет, печка (основные функции)
3. **Затем:** Послушать, не стучит ли где (диагностика проблем)
4. **В конце:** Решить, куда ехать (планирование)

## 💎 **Главный совет на первые дни**

**Не старайся всё переделать сразу!**

Сначала:
1. **Понять** как работает система
2. **Зафиксировать** текущее состояние (фото, бэкапы)
3. **Наладить** самое критичное
4. **Спросить** что нужно пользователям
5. **Потом** уже улучшать

**Запомни:** Первые 30 дней — твоя "неприкосновенность". Можно задавать глупые вопросы, просить помощи, говорить "я ещё не знаю". Потом такой возможности не будет.

---

## 🆘 **Если совсем туго**

Что делать, когда:
- **Ничего не работает** → Начать с интернета и электричества
- **Никто ничего не знает** → Звонить провайдерам, искать договора
- **Всё сломалось сразу** → Расставить приоритеты: что приносит деньги?
- **Начальник требует невозможного** → Честно сказать: "Сделаю, но нужно 3 дня и вот что..."

**Удачи, коллега!** Первый месяц — самый сложный, потом будет легче 👍

*P.S. Сохрани эту инструкцию в телефоне, она пригодится не раз.*
