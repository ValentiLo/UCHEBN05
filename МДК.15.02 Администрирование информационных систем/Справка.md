Отличный вопрос! Вот **полное руководство для новичка**, где брать команды и как их изучать.

## **1. Главные источники для новичка**

### **А) Встроенная справка в Windows (самое важное!)**
```powershell
# Для ЛЮБОЙ команды PowerShell
Get-Help Get-EventLog           # Базовая справка
Get-Help Get-EventLog -Full     # Полная справка с примерами
Get-Help Get-EventLog -Examples # Только примеры использования

# Если команда не найдена, ищем по ключевым словам
Get-Command *event*             # Найти все команды с "event"
Get-Command -Module Microsoft.PowerShell.Management  # Команды модуля
```

### **Б) Утилиты командной строки (CMD)**
```cmd
# Справка по любой команде CMD
help systeminfo
systeminfo /?

# Список всех команд CMD
help
```

## **2. Где искать команды по задачам**

### **Для мониторинга сервера:**
```powershell
# 1. Службы
Get-Command *service*           # Найдем: Get-Service, Start-Service, Stop-Service
Get-Command *process*           # Найдем: Get-Process

# 2. Сеть
Get-Command *network*           # Get-NetIPAddress, Test-NetConnection
Get-Command *ping*              # Test-Connection

# 3. Диски и память
Get-Command *disk*              # Get-Disk, Get-Volume
Get-Command *memory*            # Get-Counter "\Memory\Available MBytes"
```

## **3. Практические советы новичку**

### **Совет 1: Начните с простых команд**
```powershell
# Что работает всегда:
ipconfig                     # Сетевые настройки
systeminfo                   # Информация о системе
tasklist                     # Список процессов
services.msc                 # Службы (графически)
eventvwr.msc                 # Просмотр событий (графически)

# В PowerShell:
Get-ComputerInfo             # Вся информация о компьютере
Get-HotFix                   # Установленные обновления
```
**Просто запомните:** Все, что делаете в графическом интерфейсе, можно сделать командой.

### **Совет 2: Используйте псевдонимы (алиасы)**
PowerShell имеет короткие алиасы для Linux-подобных команд:
```powershell
ls        # Вместо Get-ChildItem
ps        # Вместо Get-Process
cat       # Вместо Get-Content
man       # Вместо Get-Help
```
Но лучше учить полные имена команд.

### **Совет 3: Экспериментируйте безопасно**
```powershell
# Команды ТОЛЬКО для чтения (безопасны):
Get-*                       # Все команды с Get - только читают
Show-*                      # Показывают информацию

# Команды, которые меняют систему (осторожно!):
Set-*, Start-*, Stop-*, Remove-*, New-*
```

## **6. Что делать, если не знаешь команду**

### **Алгоритм поиска:**
1. **Определите задачу**: "Мне нужно проверить свободное место на диске"
2. **Переведите на английский**: "check disk space windows"
3. **Поищите в Google**: "Windows command line check disk space"
4. **Нашли команду**: `wmic logicaldisk get size,freespace,caption`
5. **Проверьте справку**: `wmic /?` или `Get-Help Get-Volume`
6. **Попробуйте с ключом `/help` или `/?`**

### **Пример поиска для вашей задачи:**
**Задача**: "Посмотреть события загрузки Windows"
**Поиск**: "Windows check boot events command line"
**Находки**: 
- `eventvwr` (графически)
- `wevtutil` (командная строка)
- `Get-EventLog` (PowerShell)

## **7. Частые ошибки новичков и решения**

```powershell
# ОШИБКА: "команда не найдена"
# РЕШЕНИЕ:
# 1. Проверьте, в той ли консоли (PowerShell, а не CMD)
# 2. Проверьте правильность написания
# 3. Используйте Tab для автодополнения: Get-Eve[Tab]

# ОШИБКА: "отказано в доступе"
# РЕШЕНИЕ: Запустите консоль "от имени администратора"

# ОШИБКА: непонятный вывод
# РЕШЕНИЕ: Используйте Format-Table или Export-CSV
Get-Service | Format-Table Name, Status -AutoSize
```

## **8. Полезные команды, которые стоит выучить первыми**

```powershell
# 1. Информация о системе
systeminfo
msinfo32.exe           # Графическая утилита

# 2. Службы
services.msc           # Графически
sc query               # Командная строка
Get-Service            # PowerShell

# 3. События
eventvwr.msc           # Графически
wevtutil qe System /rd:true /c:5  # Командная строка

# 4. Сеть
ipconfig /all
ping -t 8.8.8.8
tracert google.com

# 5. Диски
chkdsk C:
fsutil volume diskfree C:
```

## **9. Создайте свою "шпаргалку"**

Создайте файл `my_commands.txt` и записывайте туда найденные команды:

```
# Мониторинг
systeminfo | find "Boot Time"      # Время загрузки
tasklist | findstr "chrome"        # Найти процесс
netstat -an | find ":80"           # Кто использует порт 80

# Диски
wmic logicaldisk get size,freespace,caption  # Место на дисках
dir C:\ /s | find "файл"           # Поиск файла

# Сеть
ping -n 5 ya.ru                    # Проверить доступность
ipconfig /flushdns                 # Очистить DNS кэш
```

## **Главный совет:**
**Не запоминайте все команды — запомните КАК ИХ НАЙТИ.** 
90% работы администратора — это умение быстро найти нужную информацию в Google и официальной документации.

**Начните с:** 
1. Откройте PowerShell
2. Введите `Get-Command` и посмотрите, что есть
3. Выберите 3 команды и изучите их через `Get-Help команда -Examples`
4. Попробуйте их выполнить

**Лучший способ учиться:** Решать реальные задачи. 
- "Почему медленно работает сервер?"
- "Куда пропало место на диске?" 
- "Почему не работает принтер?"

Каждую такую задачу разбирайте по шагам, ищите команды для диагностики — так знания останутся надолго!
