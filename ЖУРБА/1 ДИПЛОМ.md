# **Проект: Разработка приложения для анализа использования таблиц и поиска запрещенного кода в хранилище данных финансового департамента**

## **1. Анализ проблемы**

### **Контекст:**
Финансовый департамент крупной корпорации использует хранилище данных (Data Warehouse) на основе:
- **Технологий:** SQL Server/Oracle/PostgreSQL
- **Объем:** 500+ таблиц, 2+ ТБ данных
- **Пользователи:** 200+ аналитиков, разработчиков
- **Проблемы:**
  - Неконтролируемое использование таблиц
  - Нарушение стандартов разработки
  - Неэффективные запросы
  - Риски безопасности данных

### **Запрещенные практики (примеры):**
```sql
-- 1. SELECT * без фильтров
SELECT * FROM financial_transactions;  -- ЗАПРЕЩЕНО!

-- 2. Коррелированные подзапросы в цикле
UPDATE accounts SET balance = (
    SELECT SUM(amount) FROM transactions 
    WHERE account_id = accounts.id
);  -- ЗАПРЕЩЕНО!

-- 3. Хардкод значений
DELETE FROM users WHERE status = 5;  -- ЗАПРЕЩЕНО!

-- 4. Отсутствие индексов в JOIN
SELECT * FROM table1 JOIN table2 ON table1.id = table2.id;  -- ЗАПРЕЩЕНО без индекса!

-- 5. NOLOCK в финансовых транзакциях
SELECT * FROM accounts WITH(NOLOCK);  -- ЗАПРЕЩЕНО!
```

### **4.1 Модуль анализа запросов (Query Analyzer)**
```python
class QueryAnalyzer:
    def analyze_query(self, sql_query: str, db_type: str) -> AnalysisResult:
        """
        Анализ SQL запроса на предмет:
        1. Производительности
        2. Безопасности
        3. Соответствия стандартам
        """
        analysis = {
            'performance_issues': self._find_performance_issues(sql_query),
            'security_violations': self._find_security_violations(sql_query),
            'standard_violations': self._find_standard_violations(sql_query),
            'table_usage': self._extract_table_usage(sql_query),
            'query_complexity': self._calculate_complexity(sql_query)
        }
        return analysis
    
    def _find_standard_violations(self, sql_query: str) -> List[Violation]:
        """Поиск запрещенных конструкций"""
        violations = []
        
        # Паттерны запрещенного кода
        forbidden_patterns = [
            (r'SELECT\s+\*\s+FROM', 'SELECT * без указания колонок'),
            (r'DELETE\s+FROM\s+\w+\s+WHERE\s+\d+', 'Хардкод значений в DELETE'),
            (r'WITH\(NOLOCK\)', 'Использование NOLOCK в финансовых операциях'),
            (r'JOIN\s+\w+\s+ON\s+\w+\.\w+\s*=\s*\w+\.\w+', 'JOIN без индексов'),
            (r'UPDATE\s+\w+\s+SET\s+\w+\s*=\s*\(SELECT', 'Коррелированные подзапросы в UPDATE'),
        ]
        
        for pattern, description in forbidden_patterns:
            if re.search(pattern, sql_query, re.IGNORECASE):
                violations.append(Violation(
                    type='STANDARD_VIOLATION',
                    description=description,
                    severity='HIGH',
                    position=self._find_position(sql_query, pattern)
                ))
        
        return violations
```

### **4.2 Модуль мониторинга использования таблиц**
```python
class TableUsageMonitor:
    def __init__(self, db_connections: Dict):
        self.db_connections = db_connections
        self.usage_stats = {}
        
    def collect_usage_statistics(self) -> Dict:
        """Сбор статистики использования таблиц"""
        statistics = {}
        
        for db_name, connection in self.db_connections.items():
            # Получение статистики из системных таблиц
            stats = self._query_system_tables(connection)
            
            # Анализ частоты использования
            for table, usage in stats.items():
                statistics.setdefault(table, {
                    'read_operations': 0,
                    'write_operations': 0,
                    'last_accessed': None,
                    'users': set(),
                    'query_patterns': []
                })
                
                statistics[table]['read_operations'] += usage['reads']
                statistics[table]['write_operations'] += usage['writes']
                statistics[table]['users'].update(usage['users'])
                
            # Определение "горячих" таблиц
            hot_tables = self._identify_hot_tables(statistics)
            
        return {
            'statistics': statistics,
            'hot_tables': hot_tables,
            'unused_tables': self._find_unused_tables(statistics)
        }
    
    def _identify_hot_tables(self, stats: Dict) -> List[HotTable]:
        """Идентификация таблиц с высокой нагрузкой"""
        hot_tables = []
        
        for table_name, data in stats.items():
            total_ops = data['read_operations'] + data['write_operations']
            
            if total_ops > self.HOT_TABLE_THRESHOLD:
                hot_tables.append(HotTable(
                    name=table_name,
                    total_operations=total_ops,
                    read_write_ratio=data['read_operations'] / max(1, data['write_operations']),
                    users_count=len(data['users']),
                    recommendation=self._generate_recommendation(data)
                ))
        
        return sorted(hot_tables, key=lambda x: x.total_operations, reverse=True)
```

```python
class AnomalyDetector:
    def __init__(self):
        self.models = {
            'query_pattern': MLModel('query_pattern_detector'),
            'access_time': MLModel('access_time_anomaly'),
            'data_volume': MLModel('data_volume_anomaly')
        }
        
    def detect_anomalies(self, query_logs: List[QueryLog]) -> List[Anomaly]:
        """Обнаружение аномалий в использовании БД"""
        anomalies = []
        
        # 1. Аномальные паттерны запросов
        query_anomalies = self._detect_query_pattern_anomalies(query_logs)
        anomalies.extend(query_anomalies)
        
        # 2. Аномальное время доступа
        time_anomalies = self._detect_time_anomalies(query_logs)
        anomalies.extend(time_anomalies)
        
        # 3. Аномальные объемы данных
        volume_anomalies = self._detect_volume_anomalies(query_logs)
        anomalies.extend(volume_anomalies)
        
        # 4. Аномальные пользователи
        user_anomalies = self._detect_user_anomalies(query_logs)
        anomalies.extend(user_anomalies)
        
        return self._prioritize_anomalies(anomalies)
    
    def _detect_query_pattern_anomalies(self, logs: List[QueryLog]) -> List[Anomaly]:
        """Обнаружение аномальных паттернов запросов"""
        anomalies = []
        
        for log in logs:
            # Проверка на необычные JOIN
            if self._is_unusual_join(log.query):
                anomalies.append(Anomaly(
                    type='UNUSUAL_JOIN_PATTERN',
                    severity='MEDIUM',
                    description=f'Необычный JOIN в запросе: {log.query[:100]}...',
                    query_id=log.id,
                    user=log.user
                ))
            
            # Проверка на сканирование большого объема данных
            if self._is_large_scan(log):
                anomalies.append(Anomaly(
                    type='LARGE_TABLE_SCAN',
                    severity='HIGH',
                    description=f'Сканирование большого объема данных: {log.rows_affected} строк',
                    query_id=log.id,
                    user=log.user
                ))
        
        return anomalies
```

### **5.1 Статический анализ SQL**
```python
class SQLStaticAnalyzer:
    """Статический анализ SQL запросов"""
    
    def analyze(self, sql: str) -> AnalysisResult:
        # 1. Парсинг SQL
        parsed = self._parse_sql(sql)
        
        # 2. Построение AST
        ast = self._build_ast(parsed)
        
        # 3. Анализ AST на предмет нарушений
        violations = self._traverse_ast(ast)
        
        # 4. Сложность запроса
        complexity = self._calculate_complexity(ast)
        
        # 5. Рекомендации по оптимизации
        recommendations = self._generate_recommendations(ast, violations)
        
        return AnalysisResult(
            violations=violations,
            complexity_score=complexity,
            recommendations=recommendations,
            execution_plan=self._generate_execution_plan(ast)
        )
    
    def _traverse_ast(self, node: ASTNode) -> List[Violation]:
        """Обход AST и поиск нарушений"""
        violations = []
        
        if isinstance(node, SelectNode):
            # Проверка SELECT *
            if node.has_wildcard_select():
                violations.append(Violation(
                    type='SELECT_WILDCARD',
                    description='Использование SELECT *',
                    severity='MEDIUM'
                ))
            
            # Проверка отсутствия LIMIT
            if not node.has_limit() and node.has_large_result_set():
                violations.append(Violation(
                    type='NO_LIMIT',
                    description='Отсутствие LIMIT в запросе с большим результатом',
                    severity='HIGH'
                ))
        
        elif isinstance(node, JoinNode):
            # Проверка JOIN без индексов
            if not self._has_proper_indexes(node):
                violations.append(Violation(
                    type='JOIN_WITHOUT_INDEX',
                    description='JOIN без использования индексов',
                    severity='HIGH'
                ))
        
        # Рекурсивный обход дочерних узлов
        for child in node.children:
            violations.extend(self._traverse_ast(child))
        
        return violations
```

```python
class MLAnomalyDetector:
    """ML-модель для обнаружения аномалий"""
    
    def __init__(self):
        # Модель для обнаружения аномальных запросов
        self.query_model = IsolationForest(contamination=0.1)
        
        # Модель для временных аномалий
        self.time_model = AutoEncoder(input_dim=24)
        
        # Модель для пользовательского поведения
        self.user_model = OneClassSVM()
        
    def train(self, historical_data: Dataset):
        """Обучение моделей на исторических данных"""
        # Подготовка данных
        query_features = self._extract_query_features(historical_data.queries)
        time_features = self._extract_time_features(historical_data.timestamps)
        user_features = self._extract_user_features(historical_data.users)
        
        # Обучение моделей
        self.query_model.fit(query_features)
        self.time_model.fit(time_features)
        self.user_model.fit(user_features)
        
    def predict(self, new_data: QueryData) -> AnomalyPrediction:
        """Предсказание аномалий для новых данных"""
        predictions = {
            'query_anomaly': self.query_model.predict(new_data.query_features),
            'time_anomaly': self.time_model.predict(new_data.time_features),
            'user_anomaly': self.user_model.predict(new_data.user_features)
        }
        
        # Агрегация предсказаний
        combined_score = self._combine_predictions(predictions)
        
        return AnomalyPrediction(
            is_anomaly=combined_score > self.THRESHOLD,
            confidence=combined_score,
            details=predictions
        )
```

```typescript
// VS Code extension для анализа SQL в реальном времени
class SQLAnalyzerExtension {
  constructor(private context: vscode.ExtensionContext) {
    // Регистрация провайдера для SQL файлов
    vscode.languages.registerCodeActionsProvider(
      'sql',
      new SQLCodeActionProvider(),
      { providedCodeActionKinds: [vscode.CodeActionKind.QuickFix] }
    );
    
    // Подсветка проблем
    vscode.languages.registerDocumentHighlightProvider(
      'sql',
      new SQLHighlightProvider()
    );
  }
  
  // Проверка SQL при сохранении
  private async onDocumentSave(document: vscode.TextDocument) {
    if (document.languageId === 'sql') {
      const analysis = await this.analyzeSQL(document.getText());
      
      // Показать проблемы в Problems panel
      this.showProblems(analysis.violations, document.uri);
      
      // Предложения по исправлению
      this.showSuggestions(analysis.suggestions);
    }
  }
  
  // Быстрый анализ SQL
  private async analyzeSQL(sql: string): Promise<AnalysisResult> {
    const response = await fetch(`${this.config.apiUrl}/analyze/query`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ sql, db_type: this.config.dbType })
    });
    
    return response.json();
  }
}

// Провайдер быстрых исправлений
class SQLCodeActionProvider implements vscode.CodeActionProvider {
  provideCodeActions(
    document: vscode.TextDocument,
    range: vscode.Range
  ): vscode.CodeAction[] {
    const actions: vscode.CodeAction[] = [];
    
    // Найти нарушение в текущей позиции
    const violation = this.findViolationAtPosition(document, range.start);
    
    if (violation) {
      // Предложить исправление для SELECT *
      if (violation.type === 'SELECT_WILDCARD') {
        const fixAction = new vscode.CodeAction(
          'Заменить SELECT * на конкретные колонки',
          vscode.CodeActionKind.QuickFix
        );
        
        fixAction.edit = new vscode.WorkspaceEdit();
        fixAction.edit.replace(
          document.uri,
          violation.range,
          this.generateColumnList(violation.table)
        );
        
        actions.push(fixAction);
      }
    }
    
    return actions;
  }
}
```

### **11.1 Меры безопасности**
```python
class SecurityManager:
    def __init__(self):
        self.encryption_key = self._load_encryption_key()
        self.audit_logger = AuditLogger()
    
    def encrypt_sensitive_data(self, data: str) -> str:
        """Шифрование чувствительных данных"""
        cipher = Fernet(self.encryption_key)
        encrypted = cipher.encrypt(data.encode())
        return encrypted.decode()
    
    def sanitize_sql_input(self, sql: str) -> str:
        """Санітизация SQL входных данных"""
        # Удаление опасных конструкций
        dangerous_patterns = [
            r'--.*$',  # Комментарии
            r';.*$',   # Multiple statements
            r'\b(DROP|DELETE|TRUNCATE)\b',
            r'\b(UNION\s+ALL?\s+SELECT)\b',
            r'\b(EXEC\s*\(|EXECUTE\s*\(|sp_executesql)\b'
        ]
        
        for pattern in dangerous_patterns:
            sql = re.sub(pattern, '', sql, flags=re.IGNORECASE)
        
        return sql.strip()
    
    def check_permissions(self, user: User, action: str, resource: str) -> bool:
        """Проверка прав доступа"""
        # RBAC проверка
        user_roles = self._get_user_roles(user)
        required_permission = f"{action}:{resource}"
        
        for role in user_roles:
            if required_permission in role.permissions:
                # Логирование доступа
                self.audit_logger.log_access(
                    user=user,
                    action=action,
                    resource=resource,
                    allowed=True
                )
                return True
        
        # Логирование отказа в доступе
        self.audit_logger.log_access(
            user=user,
            action=action,
            resource=resource,
            allowed=False
        )
        
        return False
```
