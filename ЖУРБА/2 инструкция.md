# **Для новичка: Простой порядок запуска и выполнения**

Представь, что ты устанавливаешь новую программу на компьютер. Вот пошаговая инструкция:

## **1. Подготовка (как установить программу)**

### **Шаг 1: Установи необходимые программы**
```bash
# 1. Установи Python (если нет)
# Скачай с python.org → Установи → Отметь "Add Python to PATH"

# 2. Установи Git (если нет)
# Скачай с git-scm.com → Установи

# 3. Проверь установку в командной строке (cmd или PowerShell):
python --version  # Должна быть версия 3.8+
git --version     # Должна быть какая-то версия
```

### **Шаг 2: Получи код программы**
```bash
# Открой командную строку и перейди в нужную папку
cd C:\Users\ТвоеИмя\Documents\Projects

# Склонируй проект с GitHub
git clone https://github.com/ваш-репозиторий/db-analyzer.git

# Перейди в папку проекта
cd db-analyzer
```

## **2. Быстрый запуск (самый простой способ)**

### **Способ A: Запуск через Docker (рекомендуется новичкам)**

**Docker — это как "виртуальная коробка" со всем готовым внутри.**

1. **Установи Docker Desktop:**
   - Скачай с docker.com
   - Установи
   - Перезагрузи компьютер

2. **Запусти программу одной командой:**
```bash
# В папке проекта выполни:
docker-compose up

# Жди, пока все загрузится...
# Готово! Программа работает!
```

3. **Открой в браузере:**
   - Открой браузер
   - Перейди по адресу: **http://localhost:3000**
   - Видишь интерфейс? Значит всё работает!

### **Способ B: Запуск вручную (если хочешь понять как работает)**

**Как готовить обед из полуфабрикатов:**

1. **Установи зависимости:**
```bash
# Установи библиотеки Python
pip install -r requirements.txt

# Установи Node.js для фронтенда (скачай с nodejs.org)
npm install
```

2. **Запусти части программы:**
```bash
# В ОДНОМ окне терминала запусти сервер:
python main.py

# В ДРУГОМ окне терминала запусти фронтенд:
npm start
```

## **3. Как пользоваться программой (простыми словами)**

### **Ситуация 1: Хочу проверить SQL запрос**
```
1. Открываешь сайт http://localhost:3000
2. Видишь поле для ввода SQL
3. Вводишь: SELECT * FROM users
4. Нажимаешь "Анализировать"
5. Получаешь ответ:
   - ❌ ОШИБКА: Не используй SELECT *
   - ✅ ИСПРАВЬ НА: SELECT id, name FROM users
```

### **Ситуация 2: Хочу посмотреть, какие таблицы самые "горячие"**
```
1. В меню выбираешь "Мониторинг"
2. Смотришь графики:
   - Какие таблицы чаще всего используют
   - Кто их использует
   - Когда пиковая нагрузка
```

### **Ситуация 3: Хочу найти запрещенный код**
```
1. Выбираешь "Сканирование"
2. Выбираешь базу данных
3. Нажимаешь "Начать сканирование"
4. Ждешь 5-10 минут
5. Получаешь отчет с ошибками
```

## **4. Примеры использования (из реальной жизни)**

### **Пример 1: Ты — разработчик**
```sql
-- Ты написал запрос:
SELECT * FROM accounts WHERE user_id = 123;

-- Программа тебе скажет:
"⚠️ Не используй SELECT * 
✅ Напиши: SELECT account_id, balance FROM accounts"
```

### **Пример 2: Ты — аналитик**
```
Ты часто запускаешь отчеты и они работают медленно.

Программа покажет:
1. Какие таблицы ты используешь
2. Почему они медленные
3. Как ускорить запросы
```

### **Пример 3: Ты — руководитель**
```
Тебе нужно понять:
1. Кто что делает в базе
2. Есть ли риски безопасности
3. Оптимально ли используется техника

Программа даст отчеты:
- Кто самый активный пользователь
- Какие запросы опасны
- Где можно сэкономить
```

## **5. Что делать, если не работает**

### **Проблема: "Команда не найдена"**
```
Решение:
1. Проверь, установлен ли Python: python --version
2. Если нет → Установи Python
3. Перезапусти командную строку
```

### **Проблема: "Порт уже занят"**
```
Решение:
1. Закрой другие программы
2. Или поменяй порт в настройках
3. Или перезагрузи компьютер
```

### **Проблема: "Нет доступа к базе"**
```
Решение:
1. Проверь логин и пароль
2. Проверь, работает ли база данных
3. Проверь настройки подключения
```

## **7. Частые вопросы новичков**

### **Вопрос: "Зачем мне это нужно?"**
```
Ответ: 
1. Чтобы не делать ошибок в SQL
2. Чтобы найти проблемы до того, как они создадут сбои
3. Чтобы понимать, что происходит в базе данных
```

### **Вопрос: "Это сложно настроить?"**
```
Ответ:
С Docker - 3 шага:
1. Установить Docker
2. Скопировать команду
3. Запустить

Без Docker - 10-15 шагов, но тоже реально
```

### **Вопрос: "Что делать с результатами?"**
```
Ответ:
1. Если нашел ошибку → исправь
2. Если нашел медленный запрос → оптимизируй
3. Если нашел нарушение правил → сообщи команде
```
