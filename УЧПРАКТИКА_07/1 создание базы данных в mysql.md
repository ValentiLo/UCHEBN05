В MySQL Workbench вам нужно выполнить несколько простых шагов, чтобы увидеть таблицу с результатами:

## Шаги для отображения таблицы:

1. **Создайте базу данных** (если ещё не создана):
   ```sql
   CREATE DATABASE IF NOT EXISTS test_db;
   USE test_db;
   ```

2. **Создайте таблицу** с вашим кодом:
   ```sql
   CREATE TABLE trip(
       trip_id INT PRIMARY KEY AUTO_INCREMENT, 
       name VARCHAR(30), 
       city VARCHAR(25), 
       per_diem DECIMAL(8, 2), 
       date_first DATE, 
       date_last DATE
   );
   ```

3. **Вставьте данные** (ваш INSERT код)

4. **Для просмотра результатов:**
   - **Нажмите кнопку ⚡ (молния)** в панели инструментов (или используйте Ctrl+Enter)
   - **ИЛИ** выберите в меню: `Query` → `Execute (All or Selection)`

## Где смотреть результаты:

После выполнения запроса `SELECT * FROM trip;`:

1. **Результаты появятся в нижней части окна** в виде таблицы
2. **Посмотрите на панели внизу** - там есть несколько вкладок:
   - **Results Grid** (Сетка результатов) - здесь таблица
   - **Action Output** (Вывод действий) - сообщения о выполнении
   - **Query Statistics** (Статистика запроса)

## Если не видно панели результатов:

1. **Проверьте, что запрос выполнен** (в нижней панели "Action Output" должно быть "Query executed successfully")
2. **Разверните панель результатов** - потяните за разделитель вверх
3. **Если панель скрыта**, выберите в меню: `View` → `Panels` → `Show Results Panel`

## Простой тест:

Выполните этот простой тестовый запрос:
```sql
SELECT 1+1 AS result;
```

Если вы увидите таблицу с одним значением 2, значит всё работает правильно.

**Важно:** Вы должны выделить запрос, который хотите выполнить, ИЛИ поместить курсор в нужный запрос, ИЛИ выполнять все запросы по очереди.
