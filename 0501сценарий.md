### **Фр. 1. Организационный момент и целеполагание (10 минут)**

**Содержание фрагмента:**  
1. Приветствие. Проверка присутствующих.  
2. Объявление темы занятия: «Разработка руководства оператора».  
3. Формулировка целей занятия (запись на доске):
   - **Знать:** структуру и требования к руководству оператора по ГОСТ 2.601-2019.
   - **Уметь:** разрабатывать разделы руководства оператора.
   - **Владеть:** навыками оформления технической документации в MS Word.
4. Мотивация: «Руководство оператора — обязательный документ для любой информационной системы».

---

### **Фр. 2. Теоретический блок (30 минут)**

**Содержание фрагмента:**  
1. **Лекция преподавателя** (с использованием презентации):
   - Понятие и назначение руководства оператора.
   - Нормативная база: ГОСТ 2.601-2019 «ЕСКД. Эксплуатационные документы».
   - Обязательные разделы руководства:
     - Титульный лист
     - Введение
     - Назначение и условия применения
     - Состав системы
     - Подготовка к работе
     - Порядок работы
     - Техническое обслуживание
     - Возможные неисправности и методы их устранения
     - Приложения
   - Требования к оформлению: шрифты, поля, нумерация страниц.

---

### **Фр. 3. Практическая часть (40 минут)**

**Фр. 3.1. Инструктаж по выполнению задания (5 минут)**  
**Содержание:**  
- Преподаватель раздаёт шаблон руководства оператора в формате .docx (соответствующий ГОСТ).
- Объясняет задание: «Используя шаблон, заполнить недостающие разделы руководства для учебной информационной системы “Библиотека”».
- Акцентирует внимание на необходимости использования MS Visio для создания схем (архитектура системы, блок-схемы алгоритмов).

**Фр. 3.2. Самостоятельная индивидуальная работа студентов (30 минут)**  
**Содержание:**  
- Студенты работают за персональными компьютерами.
- **Задание:**
  1. Открыть шаблон «Руководство_оператора_шаблон.docx».
  2. Заполнить разделы: «Назначение системы», «Состав системы», «Порядок работы».
  3. В разделе «Состав системы» создать схему архитектуры системы в MS Visio и вставить её в документ.
  4. Оформить документ в соответствии с требованиями ГОСТ.
- **Исходные данные для заполнения** (выдаются на листе):
  - Назначение системы: автоматизация учёта книг и читателей.
  - Состав: модуль каталога, модуль выдачи, модуль отчётности.
  - Порядок работы: запуск системы → авторизация → выбор модуля → выполнение операции.

**Фр. 3.3. Физкультминутка (5 минут)**  
- Комплекс упражнений для снятия напряжения с глаз и спины.

---

### **Фр. 4. Контроль и закрепление (15 минут)**

**Фр. 4.1. Фронтальный опрос (10 минут)**  
**Содержание:**  
- Преподаватель задаёт вопросы группе для проверки усвоения терминов:
  1. Что такое руководство оператора?
  2. Перечислите обязательные разделы руководства.
  3. Какой ГОСТ регламентирует оформление?
  4. Какие программы используются для создания схем?

**Фр. 4.2. Сбор и оценка работ (5 минут)**  
- Студенты сохраняют работы в сети колледжа в папку «Сдача_работ_15».
- Преподаватель объявляет критерии оценки:
  - Полнота заполнения разделов (0-3 балла)
  - Соответствие оформления ГОСТ (0-3 балла)
  - Качество схемы (0-2 балла)
  - Аккуратность (0-2 балла)

---

### **Фр. 5. Подведение итогов, рефлексия, домашнее задание (5 минут)**

**Содержание фрагмента:**  
1. **Итоги:** краткий обзор выполненной работы, типичные ошибки.
2. **Рефлексия:** «Что нового вы узнали сегодня? С какими трудностями столкнулись?»
3. **Домашнее задание:**
   - Закончить оформление руководства оператора (если не успели на занятии).
   - Подготовить устный ответ на вопрос: «В чём разница между руководством оператора и руководством пользователя?»
4. **Организационное окончание:** уборка рабочих мест.
