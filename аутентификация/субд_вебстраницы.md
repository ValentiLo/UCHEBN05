# 🗄️ **СУБД для веб-страниц: от простых к сложным**

## 📊 **Обзор вариантов**

| Тип | СУБД | Сложность | Когда использовать |
|-----|-------|-----------|-------------------|
| **Браузерные** | IndexedDB | Низкая | Офлайн-приложения, кеширование |
| **Браузерные** | LocalStorage | Очень низкая | Простые данные, настройки |
| **Серверные** | SQLite | Низкая | Десктопные/мобильные приложения |
| **Серверные** | MySQL/PostgreSQL | Средняя | Веб-сайты, блоги, интернет-магазины |
| **Облачные** | Firebase | Низкая | Быстрый старт, мобильные приложения |
| **Облачные** | Supabase | Средняя | Современные веб-приложения |

---

## 🎯 **Рекомендации по выбору**

### **1. Для начинающих / учебных проектов:**
- **LocalStorage** — максимально просто
- **JSON Server** — имитация REST API
- **SQLite в браузере** — через WebAssembly

### **2. Для реальных проектов:**
- **PostgreSQL** + **Node.js/Express** — лучшая комбинация
- **Firebase** — если нужно быстро и без своего сервера
- **MySQL** — если есть опыт с PHP

### **3. Для SPA (React/Vue/Angular):**
- **Supabase** — готовый бэкенд
- **Appwrite** — open-source альтернатива Firebase
- **Directus** — headless CMS с API

## 🔥 **Топ 5 вариантов для подключения к веб-странице**

### **1. LocalStorage (самый простой)**

```javascript
// Сохранение данных
localStorage.setItem('users', JSON.stringify([
    { id: 1, name: 'Иван', email: 'ivan@example.com' }
]));

// Получение данных
const users = JSON.parse(localStorage.getItem('users') || '[]');

// Обновление данных
const updatedUsers = users.map(user => 
    user.id === 1 ? { ...user, name: 'Иван Петров' } : user
);
localStorage.setItem('users', JSON.stringify(updatedUsers));
```

**Плюсы:**
- Нет сервера
- Работает offline
- Очень просто

**Минусы:**
- Только 5-10 МБ
- Нет сложных запросов
- Нет безопасности

### **2. IndexedDB (продвинутый браузерный вариант)**

```javascript
// Открытие базы данных
const request = indexedDB.open('MyDatabase', 1);

request.onupgradeneeded = function(event) {
    const db = event.target.result;
    
    // Создание хранилища
    const store = db.createObjectStore('users', { keyPath: 'id' });
    store.createIndex('email', 'email', { unique: true });
};

request.onsuccess = function(event) {
    const db = event.target.result;
    
    // Добавление данных
    const transaction = db.transaction('users', 'readwrite');
    const store = transaction.objectStore('users');
    
    store.add({ id: 1, name: 'Иван', email: 'ivan@example.com' });
};
```

**Плюсы:**
- До 50% свободного места на диске
- Индексы и транзакции
- Работает offline

**Минусы:**
- Сложный API
- Только в браузере

### **3. JSON Server (имитация REST API)**

```bash
# Установка
npm install -g json-server

# Создаем db.json
{
  "users": [
    { "id": 1, "name": "Иван", "email": "ivan@example.com" }
  ]
}

# Запуск сервера
json-server --watch db.json --port 3000
```

**На фронтенде:**
```javascript
// Получение всех пользователей
fetch('http://localhost:3000/users')
    .then(response => response.json())
    .then(data => console.log(data));

// Добавление пользователя
fetch('http://localhost:3000/users', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ name: 'Петр', email: 'peter@example.com' })
});
```

**Плюсы:**
- Полный REST API
- Быстрый старт
- Хорош для прототипов

**Минусы:**
- Только для разработки
- Нет безопасности

### **4. SQLite в браузере (via WebAssembly)**

```html
<script src="https://cdn.jsdelivr.net/npm/sql.js@1.6.2/dist/sql-wasm.js"></script>
<script>
initSqlJs({
    locateFile: file => `https://cdn.jsdelivr.net/npm/sql.js@1.6.2/dist/${file}`
}).then(SQL => {
    // Создание базы данных в памяти
    const db = new SQL.Database();
    
    // Создание таблицы
    db.run(`
        CREATE TABLE users (
            id INTEGER PRIMARY KEY,
            name TEXT,
            email TEXT UNIQUE
        )
    `);
    
    // Вставка данных
    db.run(
        'INSERT INTO users (name, email) VALUES (?, ?)',
        ['Иван', 'ivan@example.com']
    );
    
    // Запрос данных
    const result = db.exec('SELECT * FROM users');
    console.log(result);
});
</script>
```

**Плюсы:**
- Настоящий SQL
- Работает в браузере
- Поддержка сложных запросов

**Минусы:**
- Нужно загружать WASM (2-3 МБ)
- Только в памяти (по умолчанию)

### **5. Firebase (готовый облачный бэкенд)**

```html
<!-- Подключаем Firebase -->
<script src="https://www.gstatic.com/firebasejs/9.6.1/firebase-app.js"></script>
<script src="https://www.gstatic.com/firebasejs/9.6.1/firebase-firestore.js"></script>

<script>
// Конфигурация (получить в консоли Firebase)
const firebaseConfig = {
    apiKey: "YOUR_API_KEY",
    authDomain: "your-project.firebaseapp.com",
    projectId: "your-project",
    storageBucket: "your-project.appspot.com",
    messagingSenderId: "123456789",
    appId: "1:123456789:web:abcdef123456"
};

// Инициализация
const app = firebase.initializeApp(firebaseConfig);
const db = firebase.firestore();

// Добавление данных
db.collection('users').add({
    name: 'Иван',
    email: 'ivan@example.com',
    createdAt: firebase.firestore.FieldValue.serverTimestamp()
});

// Получение данных
db.collection('users')
    .where('email', '==', 'ivan@example.com')
    .get()
    .then(snapshot => {
        snapshot.forEach(doc => {
            console.log(doc.id, doc.data());
        });
    });
</script>
```

**Плюсы:**
- Реальная база данных
- Аутентификация из коробки
- Хостинг статики

**Минусы:**
- Платно при большом трафике
- Зависимость от Google

### **Шаг 2: Создание таблиц**

**database.sql:**
```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE posts (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(200) NOT NULL,
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### **Шаг 3: Backend на Node.js/Express**

**server.js:**
```javascript
const express = require('express');
const cors = require('cors');
const { Pool } = require('pg');

const app = express();
const port = 3000;

// Настройка CORS
app.use(cors());
app.use(express.json());

// Подключение к PostgreSQL
const pool = new Pool({
    user: 'myuser',
    host: 'localhost',
    database: 'mydatabase',
    password: 'mypassword',
    port: 5432,
});

// Проверка подключения
pool.connect((err) => {
    if (err) {
        console.error('Ошибка подключения к БД:', err);
    } else {
        console.log('✅ Подключено к PostgreSQL');
    }
});

// API для пользователей
app.get('/api/users', async (req, res) => {
    try {
        const result = await pool.query('SELECT id, username, email FROM users ORDER BY id');
        res.json(result.rows);
    } catch (err) {
        console.error(err);
        res.status(500).json({ error: 'Ошибка сервера' });
    }
});

app.post('/api/users', async (req, res) => {
    const { username, email, password } = req.body;
    
    try {
        const result = await pool.query(
            'INSERT INTO users (username, email, password_hash) VALUES ($1, $2, $3) RETURNING id, username, email',
            [username, email, password] // В реальном приложении хэшируйте пароль!
        );
        
        res.status(201).json(result.rows[0]);
    } catch (err) {
        console.error(err);
        
        if (err.code === '23505') { // Нарушение уникальности
            res.status(400).json({ 
                error: 'Пользователь с таким email или именем уже существует' 
            });
        } else {
            res.status(500).json({ error: 'Ошибка сервера' });
        }
    }
});

// API для постов
app.get('/api/posts', async (req, res) => {
    try {
        const result = await pool.query(`
            SELECT p.*, u.username 
            FROM posts p 
            JOIN users u ON p.user_id = u.id 
            ORDER BY p.created_at DESC
        `);
        res.json(result.rows);
    } catch (err) {
        console.error(err);
        res.status(500).json({ error: 'Ошибка сервера' });
    }
});

app.post('/api/posts', async (req, res) => {
    const { user_id, title, content } = req.body;
    
    try {
        const result = await pool.query(
            'INSERT INTO posts (user_id, title, content) VALUES ($1, $2, $3) RETURNING *',
            [user_id, title, content]
        );
        
        res.status(201).json(result.rows[0]);
    } catch (err) {
        console.error(err);
        res.status(500).json({ error: 'Ошибка сервера' });
    }
});

// Запуск сервера
app.listen(port, () => {
    console.log(`🚀 Сервер запущен на http://localhost:${port}`);
});
```

## 📋 **Чек-лист выбора**

**Выберите LocalStorage если:**
- Простой учебный проект
- Нет возможности настраивать сервер
- Нужен офлайн-режим

**Выберите JSON Server если:**
- Нужно быстро протестировать API
- Идёт разработка фронтенда
- Пока нет готового бэкенда

**Выберите PostgreSQL если:**
- Серьёзный проект
- Нужна надёжность и масштабируемость
- Есть опыт администрирования

**Выберите Firebase/Supabase если:**
- Нужен быстрый старт
- Не хотите администрировать сервер
- Нужна готовая аутентификация

**Выберите PocketBase если:**
- Хотите open-source решение
- Нужна админ-панель
- Предпочитаете само-хостинг

## 💡 **Рекомендация для вашего проекта**

**Для системы аутентификации:** 
1. **Начинайте с LocalStorage** для прототипа
2. **Переходите на PostgreSQL** когда нужна реальная БД
3. **Используйте PocketBase** если нужен готовый бэкенд с админкой

**Быстрый путь:**
```bash
# 1. Установите PocketBase
# 2. Запустите: pocketbase serve
# 3. Откройте админку: http://localhost:8090/_/
# 4. Создайте коллекцию "users"
# 5. Подключайтесь с фронтенда
```
