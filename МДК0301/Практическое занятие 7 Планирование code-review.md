## **Задание 1. Теоретическая часть: План проведения code-review**

Ответьте письменно на вопросы:

2. **Какие цели code-review?**
   - Поиск багов и логических ошибок

   - Автор кода

5. **Какие инструменты используются?**
   - GitHub Pull Requests / GitLab Merge Requests

## **Задание 3. Практическая часть: Найдите ошибки в коде**

Вам дан фрагмент кода. Проведите code-review и найдите все ошибки/недочёты.

### **Код для проверки:**

```python
def calc(a,b,c):
    res = a+b*c
    return res

def get_user():
    user = input("Enter name")
    age = input("Enter age")
    if age > 18:
        print("Adult")
    return user,age

file = open("data.txt")
data = file.read()
print(data)

def process_list(lst):
    for i in range(len(lst)):
        if lst[i] > 10:
            lst.remove(lst[i])
    return lst

numbers = [5, 15, 25, 10, 30]
result = process_list(numbers)
print(result)

def divide(x,y):
    return x/y

print(divide(10,0))
```

### **Что нужно найти (ответы для отчета):**

| № | Ошибка/Недочёт | Как исправить |
|---|----------------|----------------|
| 1 | Непонятные имена переменных `a,b,c` | Переименовать в `price, quantity, discount` и т.д. |
| 2 | Отсутствуют аннотации типов | Добавить `def calc(a: int, b: int, c: int) -> int:` |
| 3 | Нет docstring у функции | Добавить описание |
| 4 | `age` — строка, а сравнивается с числом | Преобразовать `age = int(input(...))` |
| 5 | Нет обработки ошибок при вводе возраста | Обернуть в `try-except` |
| 6 | Файл не закрывается | Использовать `with open(...) as file:` |
| 7 | Нет обработки ошибки при открытии файла | Добавить `try-except FileNotFoundError` |
| 8 | Удаление элементов списка во время итерации — баг | Создать новый список или идти с конца |
| 9 | Деление на ноль не обработано | Добавить проверку `if y == 0: raise ValueError` |
| 10 | Отсутствуют пробелы после запятых (PEP 8) | `calc(a, b, c)` |
| 11 | Нет проверки типа в `process_list` | Добавить `isinstance` или аннотации |

## **Задание 5. Ролевая игра «Я — рецензент»**

Представьте, что вы рецензент. Напишите замечания к коду ниже в виде комментариев.

```python
def check_password(pwd):
    # проверка пароля
    if len(pwd) < 8:
        return False
    if pwd.isalpha():
        return False
    if pwd.isdigit():
        return False
    return True
```

### **Пример замечаний (что написать в отчете):**

1. **Именование:** `pwd` лучше переименовать в `password` для ясности.
2. **Документация:** Нет docstring. Что функция возвращает? Какие требования к паролю?
3. **Логика:** Не проверяется наличие специальных символов (!@#$%).
4. **Стиль:** Комментарий `# проверка пароля` избыточен, лучше описать в docstring.
5. **Аннотации:** Нет type hints. Правильно: `def check_password(password: str) -> bool:`
6. **Тесты:** Нужно добавить проверку на `None` или пустую строку.
