# **Практическое занятие 9: Предпроектное обследование объекта автоматизации**

## **Цель занятия:**
Научиться проводить предпроектное обследование предприятия/процесса для выявления проблемных зон и определения требований к автоматизации.

---

## **1. Что такое предпроектное обследование?**

### **Определение:**
Предпроектное обследование — это **комплексный анализ** объекта автоматизации с целью:
- Понимания текущих бизнес-процессов
- Выявления проблем и "узких мест"
- Определения требований к будущей системе
- Оценки затрат и сроков

### **Аналогия из жизни:**
```
Врач перед лечением:
1. Сбор жалоб (интервью)
2. Анализ симптомов (наблюдение)
3. Диагностика (анализ документов)
4. Постановка диагноза (отчет)
5. Назначение лечения (ТЗ на автоматизацию)
```

## **2. Этапы предпроектного обследования**

### **Этап 1: Подготовка (1-2 дня)**
```markdown
Задачи:
├── Определить цели обследования
├── Сформировать команду
├── Подготовить опросники и чек-листы
└── Получить доступ к объекту
```

**Чек-лист подготовки:**
- [ ] Получено письмо-согласие от руководства
- [ ] Определены ключевые сотрудники для интервью
- [ ] Подготовлены шаблоны документов
- [ ] Запланированы встречи

### **Этап 2: Сбор информации (3-7 дней)**

#### **А) Методы сбора информации:**
```
1. Интервью с сотрудниками
   ├── Руководители (стратегия)
   ├── Менеджеры (процессы)
   └── Исполнители (операции)

2. Наблюдение за рабочими процессами
   ├── Хронометраж операций
   ├── Фиксация проблем
   └── Анализ взаимодействий

3. Анализ документов
   ├── Бизнес-процессы
   ├── Отчетные формы
   ├── Входные/выходные документы
   └── Нормативные акты

4. Анкетирование
   ├── Массовый опрос сотрудников
   └── Выявление общих проблем
```

#### **Б) Пример интервью с менеджером отдела продаж:**
```markdown
Вопросы:
1. Опишите ваш типичный рабочий день
2. Какие рутинные операции отнимают больше всего времени?
3. Какие отчеты вы готовите и кому?
4. С какими отделами взаимодействуете?
5. Какие проблемы возникают регулярно?
6. Что бы вы автоматизировали в первую очередь?
7. Какая информация вам не хватает для работы?
```

### **Задание 3: Составьте карту бизнес-процесса**

**Процесс: "Продажа товара в магазине"**
```
Текущий процесс:
1. Клиент выбирает товар
2. Продавец проверяет цену в прайсе (бумажном)
3. Проверяет наличие в 1С (часто нет доступа)
4. Если есть — пробивает чек
5. Если нет — предлагает альтернативу
6. Выписывает гарантийный талон (вручную)
7. Передает товар клиенту

Проблемы:
├── Цены в прайсе и 1С не совпадают
├── Нет доступа к 1С с торгового зала

└── Ошибки в ручном заполнении

```

### **Задание 4: Анализ и выводы**

```markdown
## Выявленные проблемы (приоритет)

1. **Расхождение данных 1С и фактических остатков**
   - Причина: Ручной ввод после приемки
   - Последствия: Потеря продаж, недовольные клиенты
   - Решение: Терминалы сбора данных на складе

   - Причина: 1 компьютер на 4 продавца

   - Решение: Планшеты/терминалы для продавцов

### Серьезные (решить во вторую очередь):
3. **Ручной документооборот**
   - Прием товара: 25 документов/неделю
   - Гарантийные талоны: ручное заполнение
   - Решение: Электронные формы, сканеры штрих-кодов

4. **Отсутствие анализа продаж**
   - Нет понимания, что продается
   - Закупают "на глаз"
   - Решение: Внедрение отчетов в 1С
```

## **6. Ошибки при проведении обследования**

### **Чего НЕ делать:**
```
1. ⛔ Начинать с предложения решений
   ✅ Сначала понять проблему

2. ⛔ Доверять только словам руководства
   ✅ Проверить на практике

3. ⛔ Игнорировать рядовых сотрудников
   ✅ Они знают реальные проблемы

4. ⛔ Копировать процессы "как есть"
   ✅ Оптимизировать перед автоматизацией

5. ⛔ Пропускать оценку стоимости
   ✅ Считайте ROI (окупаемость)
```

### **Пример расчета ROI:**
```markdown
Затраты на автоматизацию:
- Разработка: 500 000 руб
- Оборудование: 200 000 руб
- Обучение: 50 000 руб
ИТОГО: 750 000 руб

Экономия после внедрения:
- Сокращение персонала: 1 чел × 40 000 руб/мес = 480 000 руб/год
- Сокращение потерь товара: 50 000 руб/мес = 600 000 руб/год
- Увеличение продаж: 100 000 руб/мес = 1 200 000 руб/год
ИТОГО экономия: 2 280 000 руб/год

ROI = (2 280 000 - 750 000) / 750 000 × 100% = 204%
Окупаемость: 4 месяца
```
