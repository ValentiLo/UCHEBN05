### **Неделя 4: Backend для фронтенда (BFF)**
**Цель:** Создание слоя интеграции на backend

#### Теория:
1. **Backend for Frontend паттерн:**
   - Проблемы direct client-to-service
   - Преимущества BFF
   - Типы BFF (per client type, per team)

2. **API Gateway:**
   - Маршрутизация запросов
   - Агрегация данных
   - Аутентификация и авторизация
   - Кэширование
   - Логирование и мониторинг

3. **Инструменты:**
   - Express.js / Fastify для Node.js
   - Django REST Framework для Python
   - Spring Cloud Gateway для Java

#### Практика:
```javascript
// BFF на Node.js/Express
app.get('/api/dashboard', async (req, res) => {
  try {
    // Параллельные запросы к разным сервисам
    const [userData, ordersData, notificationsData] = await Promise.all([
      axios.get('http://user-service/users/current'),
      axios.get('http://order-service/orders/recent'),
      axios.get('http://notification-service/notifications/unread'),
    ]);
    
    // Агрегация данных
    res.json({
      user: userData.data,
      recentOrders: ordersData.data,
      notifications: notificationsData.data,
    });
  } catch (error) {
    res.status(500).json({ error: 'Integration failed' });
  }
});
```

// Real-time чат с Socket.io
// Server
const io = require('socket.io')(server);

io.on('connection', (socket) => {
  console.log('User connected');
  
  socket.on('joinRoom', ({ username, room }) => {
    socket.join(room);
    socket.to(room).emit('message', `${username} joined`);
  });
  
  socket.on('sendMessage', ({ room, message }) => {
    io.to(room).emit('message', message);
  });
  
  socket.on('disconnect', () => {
    console.log('User disconnected');
  });
});

// Client
const socket = io('http://localhost:3000');
socket.emit('joinRoom', { username: 'John', room: 'general' });

  addMessageToChat(message);

## 🚨 **Частые ошибки и как их избежать**

### 1. **Callback Hell в JavaScript:**
```javascript
// Плохо
getUser(userId, (user) => {
  getOrders(user.id, (orders) => {
    getProducts(orders[0].productId, (product) => {
      // ...
    });
  });
});

// Хорошо
const user = await getUser(userId);
const orders = await getOrders(user.id);
const product = await getProducts(orders[0].productId);
```

### 2. **Отсутствие обработки загрузки:**
```javascript
// Добавляйте индикаторы загрузки
const [data, setData] = useState(null);
const [loading, setLoading] = useState(false);
const [error, setError] = useState(null);

useEffect(() => {
  const fetchData = async () => {
    setLoading(true);
    try {
      const result = await api.get('/data');
      setData(result.data);
    } catch (err) {
      setError(err.message);
    } finally {
      setLoading(false);
    }
  };
  
  fetchData();
}, []);
```

### 3. **Неоптимизированные запросы:**
```javascript
// Используйте debouncing для поиска
const SearchComponent = () => {
  const [query, setQuery] = useState('');
  
  const debouncedSearch = useCallback(
    debounce((searchTerm) => {
      api.search(searchTerm);
    }, 300),
    []
  );
  
  useEffect(() => {
    debouncedSearch(query);
  }, [query, debouncedSearch]);
  
  return <input onChange={(e) => setQuery(e.target.value)} />;
};
```
